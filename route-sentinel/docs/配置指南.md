# route-sentinel 网关配置指南

> route-sentinel 是青岛地铁 ITP 平台的用户分流网关，通过 Actuator API 动态管理路由规则。本文档说明如何配置和使用。

## 一、架构概述

```
乘客请求 → Istio VS → route-sentinel → 旧 ITP / 新 ITP
                    │
                    ├── 路径匹配（Path/Query/Header/Method）
                    ├── 用户判定（legacyPredicate）
                    └── 路由转发
```

**核心组件**：
- `GatewayRouteAdminController`：Actuator API，管理路由 CRUD
- `UserRouteService`：Caffeine 缓存 + Oracle 点查，判断用户是否 legacy
- `RoutePredicateStrategy`：分流谓词策略
- `PredicateParser`：解析路由配置中的谓词定义

## 二、API 端点

### 2.1 列出所有路由
```bash
GET /actuator/gatewayroutes
```

### 2.2 新增/更新路由
```bash
POST /actuator/gatewayroutes/{routeId}
Content-Type: application/json

{
  "uri": "http://target-system:8080",
  "predicates": ["Path=/ci/app/**"],
  "operator": "admin",
  "remark": "备注"
}
```

### 2.3 删除路由
```bash
DELETE /actuator/gatewayroutes/{routeId}
Content-Type: application/json

{
  "operator": "admin",
  "remark": "删除原因"
}
```

### 2.4 查看缓存状态
```bash
GET /actuator/routecache
```
返回：`hitCount`, `missCount`, `hitRate`, `size`, `evictionCount` 等。

## 三、谓词配置语法

### 3.1 Path（路径匹配）
```json
"predicates": ["Path=/ci/app/**"]
"predicates": ["Path=/exact/path"]
```
- `/ci/app/**`：前缀匹配
- `/exact/path`：精确匹配

### 3.2 Query（查询参数匹配）
```json
"predicates": ["Query=channel,alipay"]
"predicates": ["Query=type"]  // 只检查参数存在
```
- `Query=key,value`：参数值匹配
- `Query=key`：只检查参数存在

### 3.3 Header（请求头匹配）
```json
"predicates": ["Header=X-Device-Type,smart"]
"predicates": ["Header=X-Channel"]  // 只检查 header 存在
```
- `Header=Name,Value`：header 值匹配
- `Header=Name`：只检查 header 存在

### 3.4 Method（HTTP 方法匹配）
```json
"predicates": ["Method=POST"]
"predicates": ["Method=GET,POST"]  // 多个方法（OR 逻辑）
```

### 3.5 组合规则（AND 逻辑）
```json
"predicates": [
  "Path=/ci/app/**",
  "Query=channel,alipay",
  "Method=POST"
]
```
所有谓词都必须匹配才会走此路由。

## 四、分流范围说明

### 4.1 需要用户判定的路径
只有以下路径会触发用户判定逻辑（查 `USER_ITP_REG_INFO` 表）：
- 7 条精确设备 URL：`/itptvm/ci/tvm/notiTakeTicketResult` 等
- `/fep-app/**` 前缀路径

其他路径直接走新 ITP，无需用户判定。

### 4.2 用户判定逻辑
```java
// RoutePredicateStrategy.legacyPredicate()
if (!userRouteService.isSplitPath(path)) return false;  // 不在分流范围
String thirdUserId = bizDataExtractor.extractThirdUserIdFast(request);
if (thirdUserId == null) return true;  // fail-safe 到旧 ITP
return userRouteService.isLegacy(thirdUserId);  // 查缓存
```

## 五、配置示例

### 5.1 按渠道分流
```bash
curl -X POST http://localhost:9999/actuator/gatewayroutes/alipay-route \
  -H 'Content-Type: application/json' \
  -d '{
    "uri": "http://alipay-system:8080",
    "predicates": ["Path=/ci/app/**", "Query=channel,alipay"],
    "operator": "admin",
    "remark": "支付宝渠道分流"
  }'
```

### 5.2 按设备类型分流
```bash
curl -X POST http://localhost:9999/actuator/gatewayroutes/device-route \
  -H 'Content-Type: application/json' \
  -d '{
    "uri": "http://device-system:8080",
    "predicates": ["Header=X-Device-Type,smart"],
    "operator": "admin"
  }'
```

### 5.3 紧急全切新系统（删除 legacy-route）
```bash
curl -X DELETE http://localhost:9999/actuator/gatewayroutes/legacy-route \
  -H 'Content-Type: application/json' \
  -d '{"operator": "admin", "remark": "紧急全切新系统"}'
```

## 七、性能优化

### 7.1 连接池配置
```yaml
hikari:
  maximum-pool-size: 30
  connection-timeout: 3000
  leak-detection-threshold: 60000
```

### 7.2 缓存配置
- Caffeine 缓存，`maximumSize=10_000`，TTL=5 分钟
- 启动时全量预热：`SELECT DISTINCT third_user_id FROM user_itp_reg_info`
- 预热失败会阻断启动（`IllegalStateException`）

### 7.3 日志级别
```yaml
logging:
  level:
    org.qd.scg.predicate.UserRouteService: WARN  # 仅打印 warn/error
```

## 八、故障排查

| 现象 | 检查项 |
|------|--------|
| 路由不生效 | `GET /actuator/gatewayroutes` 确认路由已注入 |
| 用户进错系统 | 检查 `USER_ITP_REG_INFO` 是否有该 `thirdUserId` |
| 网关 5xx | 检查 Actuator 落库是否成功，DB 连通性 |
| 入口没流量 | 检查 Istio VS 指向（`kubectl get vs -n itp`） |
| 缓存命中率低 | `GET /actuator/routecache` 查看 hitRate |

## 九、回滚方案

**回滚 = 把入口指回 `fep-app-svc:9101`**，网关 Pod 保留，Actuator 路由随时可重注入。

紧急全切新系统：
```bash
# 删除 legacy-route
DELETE /actuator/gatewayroutes/legacy-route
```

恢复旧系统：
```bash
# 重新注入 legacy-route
POST /actuator/gatewayroutes/legacy-route
{"uri": "http://legacy-system:8080", "predicates": ["Path=/fep-app/**"], "operator": "admin"}
```
