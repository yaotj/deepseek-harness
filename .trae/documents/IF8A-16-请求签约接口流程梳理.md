## 二、业务层：pay-sign-server

### 2.1 入口 Controller
- **文件**：[PaySignController.java](file:///d:/workspace/zr/qditp/pay-sign-server/src/main/java/com/chinasofti/huateng/paysign/controller/ci/app/PaySignController.java)
- 直接透传至 `PaySignService.requestSignInfo(request)`

### 2.2 核心业务逻辑
- **文件**：[PaySignServiceImpl.java](file:///d:/workspace/zr/qditp/pay-sign-server/src/main/java/com/chinasofti/huateng/paysign/service/impl/PaySignServiceImpl.java#L118-L157)
- **事务**：`@Transactional(rollbackFor = Exception.class)`

#### 完整流程：

```
1. 参数校验 (validateRequestSignInfo)
   └── 校验 thirdUserId、displayAccount、payChannelCode、requestSignSeq

2. normalizeVendor 编码映射
   └── 当前：仅 trim，无实际映射

3. buildRequestStartSdkInfo 调用支付平台
   └── 组装 bizData → 调用 contract 接口
   └── 成功返回 SDK 参数 JSON

4. getOrInitSignInfo 查询/初始化签约记录
   └── 先按 requestSignSeq + paymentVendor 查询
   └── 查不到则只按 requestSignSeq 查询（兼容旧数据）
   └── 还查不到则 new PaySignInfo()

5. 填充签约记录字段
   └── contractStatus = STATUS_SIGNING

6. saveSignInfo 入库（MERGE）

7. fillSuccess + 设置 requestStartSdkInfo + writeLog + return
```
