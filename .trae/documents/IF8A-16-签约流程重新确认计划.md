## 三、Proposed Changes

### 3.1 修改 normalizeVendor 方法支持 0802

**文件：** `d:\workspace\zr\qditp\pay-sign-server\src\main\java\com\chinasofti\huateng\paysign\service\impl\PaySignServiceImpl.java`

**What：** 修改 `normalizeVendor` 方法，截取 payChannelCode 前两位，将 `08` 系列映射为内部编码。

**Why：** 用户传入 `0802` 需要被正确识别为支付宝（03）。

**How：**
```java
private String normalizeVendor(String payChannelCode) {
    if (!StringUtils.hasText(payChannelCode)) {
        return null;
    }
    String code = payChannelCode.trim();
    // 截取前两位作为内部编码
    if (code.length() >= 2) {
        String prefix = code.substring(0, 2);
        if ("08".equals(prefix)) {
            // 08xx 系列映射
            String suffix = code.length() >= 3 ? code.substring(2, 3) : "";
            if ("2".equals(suffix)) {
                return "03"; // 支付宝
            }
            if ("3".equals(suffix)) {
                return "04"; // 微信
            }
        }
        // 直接匹配内部编码（兼容旧格式）
        if ("03".equals(prefix) || "04".equals(prefix)) {
            return prefix;
        }
    }
    return code;
}
```
