## 接口地址

```
http//:[ip]:[port]/[project]/ci/app/requestContractAdvisory
```

## 接口说明

信用能力咨询

## 请求参数

参数详情参见规范表 45。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| tradeNo | string | 支付交易流水号 |
| payResult | string | SUCCESS/FAIL |
| payAmount | string | 支付金额 |
| payDate | string | 支付时间 |
