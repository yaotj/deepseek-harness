# IF8A-02 请求同步密钥

> **接口编号**: IF8A-02
> **接口类型**: 请求类（APP 主动调用）
> **接口路径**: `/ci/app/requestKeyList`（account-server）/ `/requestKeyList`（key-server）
> **请求方式**: POST
> **消费端**: 地铁 APP
> **提供端**: key-server（密钥服务），由 fep-app-server 转发
> **源码位置**: `key-server/src/main/java/com/chinasofti/huateng/key/controller/KeyController.java`
> **整理时间**: 2026-07-28

---

## 一、接口功能

用户密钥同步接口。APP 调用此接口同步 HCE 消费密钥或二维码 SM2 密钥。

密钥类型判断：
- 卡类型 `03`/`04`：返回 HCE 消费 DPK（对称密钥）
- 其他卡类型：返回二维码用户 SM2 密钥对（非对称密钥）

---

## 二、请求参数

### 2.1 请求示例

```json
{
  "thirdUserId": "2088000123456789",
  "cardId": "CARD123456789",
  "cardType": "03"
}
```

### 2.2 请求字段定义

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| thirdUserId | String | 是 | 第三方用户ID | `2088000123456789` |
| cardId | String | 是 | 地铁会员卡号 | `CARD123456789` |
| cardType | String | 是 | 卡类型编码（03=HCE，其他=二维码） | `03` |

### 3.1 响应示例（HCE 卡类型 03/04）

```json
{
  "retCode": "0000",
  "retMsg": "成功",
  "keyList": [

  ]
}
```

### 3.2 响应示例（二维码卡类型）

```json
{
  "retCode": "0000",
  "retMsg": "成功",
  "keyList": [
    {
      "keyId": "01",
      "keyType": "1",
      "keyUserId": "2088000123456789",
```

### 3.3 响应字段定义

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| retCode | String | 是 | 返回码 | `0000` |
| retMsg | String | 是 | 返回消息 | `成功` |
| keyId | String | 否 | 密钥编码（00=工作密钥，01=用户非对称密钥对） | `01` |
| keyType | String | 否 | 密钥类型（0=对称密钥，1=非对称密钥） | `0` |
| keyUserId | String | 否 | 非对称密钥运算的用户标识 | `2088000123456789` |
| keyPrivate | String | 否 | 非对称用户私钥（加密后） | `encrypted_private_key` |
| keyPublic | String | 否 | 非对称用户公钥X | `public_key_x_value` |
| keyPublicEffectiveDate | String | 否 | 公钥有效期（默认7天） | `20260728` |
| signData | String | 否 | 非对称用户公钥签名数据 | `signature_data` |
| caIdx | String | 否 | 非对称公钥验签密钥索引 | `01` |
| keyWrapValue | String | 否 | 对称密钥值（HCE DPK） | `encrypted_dpk_value` |
| keyEffectiveDate | String | 否 | 对称密钥有效期 | `20260728` |
| kvc | String | 否 | 对称密钥KVC | `kvc_value` |
| reserve | String | 否 | 预留字段 | - |

## 四、业务流程

### 4.1 调用链路

```
APP
  → fep-app-server (/ci/app/requestKeyList)
    → key-server (/requestKeyList)
      → KeySyncService.requestKeyList()
        → 1. 参数校验
        → 2. 根据 cardType 判断密钥类型
        → 3. 调用 acc-security-server 生成/获取密钥
        → 4. 加密存储私钥
        → 5. 返回密钥材料
```

### 4.2 关键代码

```java
// KeyController.java:38-45
@PostMapping("/requestKeyList")
public RequestKeyListResult requestKeyList(@RequestBody RequestKeyListReqDTO request) {
    log.info("接收到IF8A-02请求同步密钥, thirdUserId={}, cardId={}, cardType={}",
            request == null ? null : request.getThirdUserId(),
            request == null ? null : request.getCardId(),
            request == null ? null : request.getCardType());
    return keySyncService.requestKeyList(request);
}
```

## 七、注意事项

1. 卡类型 `03`/`04` 返回 HCE 消费 DPK（对称密钥）
2. 其他卡类型返回二维码用户 SM2 密钥对（非对称密钥）
3. 私钥以加密形式存储和返回
4. 公钥有效期默认 7 天
5. 密钥材料由 acc-security-server 导出后转加密
