# IF8A-10 计算票价

> **接口编号**: IF8A-10
> **接口类型**: 请求类（APP 主动调用）
> **接口路径**: `/ci/app/requestTicketPriceByStation`
> **请求方式**: POST
> **消费端**: 地铁 APP / collect-ticket-server
> **提供端**: para-server（参数服务）
> **源码位置**: `para-server/src/main/java/com/chinasofti/huateng/para/controller/AppParaController.java`
> **整理时间**: 2026-07-28

---

## 一、接口功能

根据进出站车站代码计算票价。APP 或内部服务调用此接口查询两站之间的基础票价。

**注意**：此接口在项目中有多个实现入口：
- `para-server` - 标准参数服务实现
- `collect-ticket-server` - 取票服务简化实现（默认票价）
- `ticket-server` - 票务服务可能复用

---

## 二、请求参数

### 2.1 请求示例

```json
{
  "entryStationCode": "0101",
  "exitStationCode": "0102"
}
```

### 2.2 请求字段定义

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| entryStationCode | String | 是 | 进站车站代码 | `0101` |
| exitStationCode | String | 是 | 出站车站代码 | `0102` |

### 2.3 字段校验规则

1. `entryStationCode` 不能为空
2. `exitStationCode` 不能为空
3. 两站代码必须存在于当前生效的路网参数版本中

## 四、业务流程

### 4.1 para-server 实现流程

**调用链路**：
```
APP / collect-ticket-server
  → para-server (/ci/app/requestTicketPriceByStation)
    → AppParaServiceImpl.requestTicketPriceByStation()
      → 1. 参数校验（entryStationCode/exitStationCode 不能为空）
      → 2. 根据进出站查询费率等级（AppParaQueryMapper.selectFareTier）
      → 3. 根据费率等级和 FARE_TYPE=0 查询基础票价（AppParaQueryMapper.selectTicketPrice）
      → 4. 返回票价
```

**业务逻辑**：
1. 参数校验：`entryStationCode` 和 `exitStationCode` 不能为空
2. 查询费率等级：根据进出站代码查询 `FARE_MATRIX` 获取费率等级
3. 查询票价：根据费率等级查询 `BASE_FARE` 获取基础票价（`FARE_TYPE=0`）
4. 返回结果：`ticketPrice` 为字符串类型的票价（单位：分）

**关键代码**：
```java
// AppParaServiceImpl.java:66-94
public RequestTicketPriceByStationResult requestTicketPriceByStation(RequestTicketPriceByStationReqDTO request) {
    RequestTicketPriceByStationResult result = new RequestTicketPriceByStationResult();
    if (request == null || isBlank(request.getEntryStationCode()) || isBlank(request.getExitStationCode())) {
        result.setRetCode(FAIL);
        result.setRetMsg("起点站点代码或终点站点代码为空");
        return result;
    }
    Integer fareTier = appParaQueryMapper.selectFareTier(request.getEntryStationCode(), request.getExitStationCode());
    if (fareTier == null) {
        result.setRetCode(FAIL);
        result.setRetMsg("未找到站点对应费率等级");
        return result;
    }
    Integer ticketPrice = appParaQueryMapper.selectTicketPrice(fareTier);
    if (ticketPrice == null) {
        result.setRetCode(FAIL);
        result.setRetMsg("未找到费率等级对应票价");
        return result;
    }
    result.setRetCode(SUCCESS);
    result.setRetMsg("成功");
    result.setTicketPrice(String.valueOf(ticketPrice));
    return result;
}
```

### 4.2 collect-ticket-server 简化实现

collect-ticket-server 的 `requestTicketPriceByStation` 实现较为简化：
- 如果 `entryStationCode == exitStationCode`，返回票价 0
- 否则返回配置的默认票价 `collect.ticket.default-ticket-price`

**关键代码**：
```java
// TicketCollectServiceImpl.java:682-687
private int resolveTicketPrice(RequestTicketPriceByStationReqDTO request) {
    if (request.getEntryStationCode().equals(request.getExitStationCode())) {
        return 0;
    }
    return defaultTicketPrice;
}
```

## 八、注意事项

1. **para-server 实现**：通过费率矩阵查询票价，返回字符串类型的票价（单位：分）
2. **collect-ticket-server 实现**：简化实现，同站返回 0，否则返回配置的默认票价
3. **票价单位**：统一为分（integer/string），前台展示需转换为元
4. **参数版本**：票价数据基于当前生效的参数版本，由 para-server 管理
