# IF8A-12 请求退款

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/ci/app/requestRefundTicket
```

## 接口说明

请求退款,同步返回退款结果

## 请求参数

参数详情参见规范表 27。

| 字段 | 类型 | 说明 |
|------|------|------|
| entryStationCode | string | 起点站点代码 |
| exitStationCode | string | 终点站点代码 |

## 应答参数

参数详情参见规范表 28。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| ticketPrice | string | 票价单位分 |
