# IF8A-18 支付结果查询

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/ci/app/requestPayResult
```

## 接口说明

客户端收到支付插件支付成功通知，没收到服务器异步支付结果通知，客户端服务器主动向ITP平台发起支付结果查询，如果ITP平台收到支付结果直接返回支付结果；如果ITP平台也没有收到支付结果回调，ITP平台主动向第三方支付通知发起支付结果查询；返回给客户端服务器。

## 请求参数

参数详情参见规范表 39。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |

## 应答参数

参数详情参见规范表 40。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | String | 第三方用户编码 必填 |
| displayAccount | string | 签约显示账号（用于只发布微信签约界面，可以用户昵称，手机号，用户姓名） 必填 |
| payChannelCode | string | 2.7支付通道编码定义 必填 |
| requestSignSeq | string | 签约请求流水号 必填 |
| returnUrl | String | 支付插件回调签约地址 |
| authCode | String | 授权码 |
| mobilePhone | String | 手机号 |
| certNo | String | 证件号 |
| custName | String | 客户姓名 |
| token | String | 数字人民币子钱包推送专用字段 |
| payUserId | String | 数字人民币子钱包推送专用字段 |
| bankCardNo | String | 银行卡号 |
| options | String | 附加参数 |
