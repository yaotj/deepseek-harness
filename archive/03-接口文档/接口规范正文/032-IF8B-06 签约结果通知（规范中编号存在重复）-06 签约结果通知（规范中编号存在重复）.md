# IF8B-06 签约结果通知（规范中编号存在重复）

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/app/receiveSignResult
```

## 接口说明

返回签约结果通知

## 请求参数

参数详情参见规范表 67。

| 字段 | 类型 | 说明 |
|------|------|------|
| orderNo | string | 订单号 |
| refundType | string | 00: 用户提交退款
01：超时未使用自动退款 |
| refundResult | string | SUCCESS/FAIL/PROCESSING
SUCCESS—退款成功
FAIL—退款失败
PROCESSING-退款进行中 |
| refundResultDesc | string | 退款描述 |
| refundDate | string | 退款日期 |
| refundAmount | String | 退款金额 单位分 |
| orderType | String | 订单类型 
单程票0
普通日票1
全城通日票2 |

## 应答参数

参数详情参见规范表 68。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
