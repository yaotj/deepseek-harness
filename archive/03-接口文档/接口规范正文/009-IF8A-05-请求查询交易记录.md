# IF8A-05 请求查询交易记录

> **接口编号**: IF8A-05
> **接口类型**: 请求类（APP 主动调用）
> **接口路径**: `/ci/app/requestTransList`
> **请求方式**: POST
> **消费端**: 地铁 APP
> **提供端**: ticket-server（票务服务）
> **源码位置**: `ticket-server/src/main/java/com/chinasofti/huateng/ticket/controller/ci/app/TicketRideStatusController.java`
> **整理时间**: 2026-07-28

---

## 一、接口功能

查询用户交易记录接口。APP 调用此接口查询用户的历史乘车交易记录。

---

## 二、请求参数

### 2.1 请求示例

```json
{
  "thirdUserId": "2088000123456789",
  "cardId": "CARD123456789",
  "startTime": "20260101000000",
  "endTime": "20260630120000",
  "pageNo": 1,
  "pageSize": 20
}
```

### 2.2 请求字段定义

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| thirdUserId | String | 是 | 第三方用户ID | `2088000123456789` |
| cardId | String | 否 | 地铁会员卡号 | `CARD123456789` |
| startTime | String | 否 | 查询开始时间（YYYYMMDD24mmss） | `20260101000000` |
| endTime | String | 否 | 查询结束时间（YYYYMMDD24mmss） | `20260630120000` |
| pageNo | Integer | 否 | 页码，默认1 | `1` |
| pageSize | Integer | 否 | 每页数量，默认20 | `20` |

### 2.3 字段校验规则

1. `thirdUserId` 不能为空
2. `startTime`/`endTime` 为可选，如果不传则查询全部记录
3. `pageNo` 和 `pageSize` 用于分页查询

---

## 四、业务流程

### 4.1 调用链路

```
APP
  → fep-app-server (/ci/app/requestTransList)
    → ticket-server (/ci/app/requestTransList)
      → TicketRideStatusServiceImpl.findTravelList()
        → 1. 参数校验
        → 2. 根据 thirdUserId/cardId 查询 QRCodeTxnDetail
        → 3. 分页处理
        → 4. 关联查询车站名称
        → 5. 返回交易列表
```

### 4.2 业务逻辑

1. **参数校验** - 校验 `thirdUserId` 是否为空
2. **查询交易记录** - 根据 `thirdUserId` 和 `cardId` 查询 `QRCODE_TXN_DETAIL`
3. **时间过滤** - 如果 `startTime`/`endTime` 有值，则按时间范围过滤
4. **分页处理** - 根据 `pageNo`/`pageSize` 进行分页
5. **关联查询** - 关联查询车站代码对应的中文名称
6. **返回结果** - 返回交易记录列表

## 七、注意事项

1. **时间格式**：时间字段格式为 `YYYYMMDD24mmss`（如 `20260728080000`）
2. **分页参数**：`pageNo` 从 1 开始，`pageSize` 默认 20
3. **交易类型**：01=进站，02=出站，03=更新
4. **数据来源**：交易记录来自 `QRCODE_TXN_DETAIL` 表
