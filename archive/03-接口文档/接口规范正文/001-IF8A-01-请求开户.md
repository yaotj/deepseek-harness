# IF8A-01 请求开户HCE后付费

> **接口编号**: IF8A-01
> **接口类型**: 请求类（APP 主动调用）
> **接口路径**: `/ci/app/requestApplication`
> **请求方式**: POST
> **消费端**: 地铁 APP
> **提供端**: account-server（账号服务）
> **上游服务**: fep-app-server（RPC 转发）
> **源码位置**: `account-server/src/main/java/com/chinasofti/huateng/account/controller/ci/app/RequestApplicationController.java`
> **整理时间**: 2026-07-28

---

## 一、接口功能

用户开户申请接口。APP 调用此接口为用户开通 ITP 账户，生成逻辑卡号，并初始化用户注册信息。

支持开户类型：
- 二维码后付费单程票（cardType 由系统分配）
- HCE 后付费单程票（cardType=03/04）

---

## 二、请求参数

### 2.1 请求示例

```json
{
  "thirdUserId": "2088000123456789",
  "userName": "张三",
  "phone": "13800138000",
  "cardType": "03",
  "channel": "ALIPAY",
  "thirdPayId": "2088000123456789"
}
```

### 2.2 请求字段定义

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| thirdUserId | String | 是 | 第三方用户ID（支付宝 user_id） | `2088000123456789` |
| userName | String | 否 | 用户姓名 | `张三` |
| phone | String | 否 | 手机号 | `13800138000` |
| cardType | String | 是 | 卡类型编码（03=二维码，04=HCE） | `03` |
| channel | String | 是 | 渠道编码（ALIPAY/WECHAT/METRO_APP） | `ALIPAY` |
| thirdPayId | String | 否 | 第三方支付ID | `2088000123456789` |

### 2.3 字段校验规则

1. `thirdUserId` 不能为空
2. `cardType` 不能为空
3. `channel` 不能为空
4. 用户不能重复开户（同一 thirdUserId + channel）

---

## 三、响应参数

### 3.1 响应示例

```json
{
  "retCode": "0000",
  "retMsg": "成功",
  "cardId": "CARD123456789",
  "cardType": "03",
  "thirdUserId": "2088000123456789",
  "regTime": "2026-07-28 10:00:00"
}
```

### 3.2 响应字段定义

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| retCode | String | 是 | 返回码（0000=成功，9999=失败，8001=参数错误，8004=未注册用户） | `0000` |
| retMsg | String | 是 | 返回消息 | `成功` |
| cardId | String | 否 | 卡号（开户成功时返回） | `CARD123456789` |
| cardType | String | 否 | 卡类型 | `03` |
| thirdUserId | String | 否 | 第三方用户ID | `2088000123456789` |
| regTime | String | 否 | 注册时间 | `2026-07-28 10:00:00` |

### 3.3 错误码说明

| 错误码 | 含义 | 说明 |
|--------|------|------|
| 0000 | SUCCESS | 成功 |
| 9999 | FAIL | 系统异常 |
| 8001 | INVALID_PARAM | 参数无效 |
| 8004 | USER_NOT_REGISTERED | 用户未注册 |
| 8006 | CARD_ID_MISMATCH | 卡号不一致 |
| 8007 | PARTNER_ERROR | 合作伙伴验证失败 |
| 8008 | USER_UNDER_REVIEW | 用户解约审核中 |

## 四、业务流程

### 4.1 调用链路

```
地铁 APP
  → fep-app-server (/ci/app/requestApplication)
    → account-server (/ci/app/requestApplication)
      → AccountApplicationServiceImpl.requestApplication()
        → 1. 参数校验
        → 2. 检查是否已开户
        → 3. 生成票卡号
        → 4. 保存注册信息到 USER_ITP_REG_INFO
        → 5. 记录注册日志到 USER_ITP_REG_LOG
        → 6. 返回开户结果
```

### 4.2 关键代码

```java
// RequestApplicationController.java:36-40
@PostMapping("/requestApplication")
public RequestApplicationResult requestApplication(@RequestBody RequestApplicationReqDTO request) {
    log.info("接收到请求开户接口报文: {}", request);
    return accountApplicationService.requestApplication(request);
}
```

## 八、注意事项

1. 同一 `thirdUserId` + `channel` 组合只能开户一次
2. `cardId` 由系统自动生成，APP 无需传递
3. 开户成功后需调用 IF8A-02 请求同步密钥获取 HCE 密钥
4. HCE 卡数据需在闸机交易后通过 IF8A-32 回写更新
