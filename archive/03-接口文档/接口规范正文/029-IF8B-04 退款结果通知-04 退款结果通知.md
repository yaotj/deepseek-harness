# IF8B-04 退款结果通知

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/app/receiveRefundResult
```

## 接口说明

定时退款通知

## 请求参数

参数详情参见规范表 61。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |

## 应答参数

参数详情参见规范表 62。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | string | 第三方用户id |
| cardId | String | 地铁会员卡号 |
| cardType | String | 2.8	卡类型编码 |
| requestSignSeq | String | 签约流水号 |
| terminationResult | String | 解约结果
SUCCESS成功
FAIL失败 |
| terminationResultMsg | String | 结果描述 |
| terminationTime | string | 解约时间, 格式如：
YYYYMMDDHH24mmss |
