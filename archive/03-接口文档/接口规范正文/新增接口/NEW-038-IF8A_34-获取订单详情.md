# if8a_34 – 获取订单详情

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/requestTransDetail
```

## 接口说明

查询订单详情。

## 请求参数

参数详情参见规范表 79。

| 字段 | 类型 | 说明 |
|------|------|------|
| goodsCode | string | 商品编码 固定为001 |
| price | string | 价格(分) |
| quantity | String | 固定为1 |
| orderNoList | array | 单号数组 |

## 应答参数

参数详情参见规范表 80。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| orderNo | String | 补款单号 |
