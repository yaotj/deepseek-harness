# if8a_72 - 小程序票状态同步

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/ticket/syncOrder
```

## 接口说明

小程序票状态同步,小程序票支付不走ITP的支付系统，订单支付、退款状态从小程序端变更后通知ITP。

## 请求参数

参数详情参见规范表 111。

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 优惠名称 |
| amt | Int | 优惠金额（分） |
| type | String | 优惠类型
1券
2活动 |

## 应答参数

参数详情参见规范表 112。

| 字段 | 类型 | 说明 |
|------|------|------|
| orderNo | String | 订单号 |
| orderType | String | 订单类型
1日票
2旅游票 |
