# if8a_32 – 查询当前是否是单边

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/ requestSingleTrans
```

## 接口说明

查询卡状态，判断是否是进站单边，给用户做是否需要补站提醒。

## 请求参数

参数详情参见规范表 77。

| 字段 | 类型 | 说明 |
|------|------|------|
| keyBathNumber | string | 密钥批次号 |
| changeDate | string | 变更日期
YYYYMMDDHHMMSS |

## 应答参数

参数详情参见规范表 78。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
