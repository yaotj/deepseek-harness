# if8a_41 – 查询账单统计

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/ requestTransStatistics
```

## 接口说明

查询行程订单数量、金额统计，显示在乘车记录上方

## 请求参数

参数详情参见规范表 89。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| unpaidCount | int | 未支付订单数 |
| failureCount | int | 扣费失败订单数量 |

## 应答参数

参数详情参见规范表 90。

| 字段 | 类型 | 说明 |
|------|------|------|
| agreementCode | string | 协议编码 |
