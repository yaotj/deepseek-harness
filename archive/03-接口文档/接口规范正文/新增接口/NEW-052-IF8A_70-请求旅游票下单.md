# if8a_70 - 请求旅游票下单

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/ticket/ requestTravelOrder
```

## 接口说明

请求旅游票下单,旅游票为聚合单，内含多张日票。

## 请求参数

参数详情参见规范表 107。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| paymentInfo | String | 支付信息 |
| discountInfo | Object | 优惠信息对象 |

## 应答参数

参数详情参见规范表 108。

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 优惠名称 |
| amt | Int | 优惠金额（分） |
| type | String | 优惠类型
1券
2活动 |
