# if8a_61– 日票支付

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/payment/requestPay
```

## 接口说明

虚拟电子多日票支付。

## 请求参数

参数详情参见规范表 97。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| tripData | Object | 统计数据对象 |

## 应答参数

参数详情参见规范表 98。

| 字段 | 类型 | 说明 |
|------|------|------|
| totalPrice | String | 总金额（元） |
| totalDebit | string | 总支付（元） |
| totalDiscount | Object | 总优惠（元） |
| count | Int | 订单数量 |
