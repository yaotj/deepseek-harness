# if8a_26 – 请求补款下单

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/requestPayOrder
```

## 接口说明

请求生成在线补款订单，在线补款成功后，ITP需要更新补款单中的原乘车订单的状态。

## 请求参数

参数详情参见规范表 73。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | String | 第三方用户编码 |
| requestSignSeq | string | 签约请求流水号 |
| paymentVendor | string | 支付通道编码 |
| payAccountId | string | 第三方签约账号编码 |
| payAgreementNo | string | 第三方签约流水号 |
| signResult | string | SUCCESS签约成功
FAIL签约失败 |
| realNameAuthResult | string | SUCCESS 实名成功
FAIL实名失败 |

## 应答参数

参数详情参见规范表 74。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
