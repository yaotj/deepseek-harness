# IF8A-14 获取激活取票订单

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/ci/app/requestPreActiveOrderList
```

## 接口说明

获取我的订单列表,用于激活取票订单,预留接口

## 请求参数

参数详情参见规范表 31。

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | string | 用户编码 |
| orderNo | string | 订单号 |
| refundReason | String | 退款原因 |

## 应答参数

参数详情参见规范表 32。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| orderNo | string | 订单号 |
| refundType | string | 00: 用户提交退款
01：超时未使用自动退款 |
| refundResult | string | SUCCESS/FAIL/PROCESSING
SUCCESS—退款成功
FAIL—退款失败
PROCESSING-退款进行中 |
| refundResultDesc | string | 退款描述 |
| refundDate | string | 退款日期 |
| refundAmount | String | 退款金额 单位分 |
