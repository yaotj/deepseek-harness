1. 请求支付应答参数信息

|  |  |  |
| --- | --- | --- |
| 字段 | 类型 | 说明 |
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| payChannelCode | string | 2.7支付通道编码定义 |
| paymentInfo | string | 支付信息，根据payChannelCode返回内容 |
| signType | string | 00：不签名  01：sha1withrsa  02：MD5 |
| sign | string | 私钥签名sha1withrsa |
