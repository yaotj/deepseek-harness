# IF8A-07 获取线路代码

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/ci/app/requestLineCodeList
```

## 接口说明

APP请求ITP获取线路代码信息列表

## 请求参数

参数详情参见规范表 17。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | string | 第三方用户id |
| cardId | String | 地铁会员卡号 |
| cardType | String | 卡类型编码 |
| requestSignSeq | string | 签约请求流水号 |

## 应答参数

参数详情参见规范表 18。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
