## 4. 口径差异汇总（同功能不同实现）

1. **密钥管理**：旧＝操作型（明文密钥值展示＋同步密钥/审批/新增版本按钮）；新＝只读元信息（不含密钥材料）＋设备密钥同步监控。这是**有意的安全升级**（AGENTS.md §4.2 红线），非缺口。
2. **黑名单**：旧＝单表＋审批状态列（339 条）；新＝两阶段解除（加入/生效 → 解除生效，含渠道同步补偿 `compensate-add/release`），测试库 0 条。
3. **线路车站版本**：旧 1 行（一行挂多参数）；新 2 行（一行一参数，09-22 A10/A11 四列已修）。
4. **逻辑卡号**：旧＝全量卡号台账 79 万行；新＝卡池批次余量（9 票种）＋批次申请/重试。
5. **验证码**：旧 `validCode` 测试环境关闭；新 SVG 验证码原为启用（B16「形同虚设」缺陷候选），后经 IT-041 执行 SQL 关闭——2026-11-03 登录页已只剩账号/密码两框（08 记录登录无验证码）。两侧现状一致（都关）。
6. **导出**：旧＝同步 Excel 下载；新＝异步导出任务表＋「异步导出任务」监控页（08：今日 10:44 FACE_PAY_ORDER 成功 4.02KB 实测）。
7. **审计面**：新有操作日志/登录日志双页（08：登录 578 成功/577 失败全记录）；但 B17 缺陷在——审计 IP 恒 127.0.0.6（sidecar 回环），旧系统会话 Cookie 模型无此问题。
