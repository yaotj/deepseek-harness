## 共同约定

- **预期结果按代码现状写**，不照抄需求文档。每条断言都要能在库表、接口响应或日志里核对。
- 事实描述带 `文件:行号`，行号绑定建库时的 commit；代码变更后需重新核对。
- 手册预期与代码现状冲突处标 ⚠️，**不擅自裁决**，统一收敛到各域的「阻塞项与缺陷候选」页。
- 找不到实现就写「未找到」，不推断、不补造用例编号。
- 执行结果回填在用例的「结果」行，不改写链路事实段落。

## 与其他文档的关系

- `docs/business/` 是**编码前**要读的业务域提示词；本目录是**测试前**要读的可验证性说明。两者冲突时以代码为准，并在两处同步更正。
- 本目录不生成「实现率 / 进度报告」类汇总（见 `AGENTS.md` §5.3）。判断某接口是否存在，直接看 Controller 的映射注解。
