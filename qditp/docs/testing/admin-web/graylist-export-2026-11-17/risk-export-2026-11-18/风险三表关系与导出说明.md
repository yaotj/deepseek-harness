# 旧 ITP 风控三表关系与数据导出（2026-11-18 实扫）

> 事实来源：旧 ITP `http://58.56.166.170:9080/qd-omp` 登录实扫（`FuTianTest001`）。
> 数据接口：各模块 `listData?pageNo=1&pageSize=1000`（jqGrid JSON）。
> 本篇只描述**旧系统现状事实**，不做新系统设计裁定。

## 一、三者关系（核心结论）

```
风险规则管理（8 条）──┐
  定义：规则ID/名称/    │  多对多绑定
  描述/等级/最大值      │  （风险组表单里的「规则勾选」checkbox）
                        ▼
风险组管理（2 条）──────┘   名称/描述/管理编码
       │
       │ 规则被引擎执行（旧后端，本仓未见代码）
       ▼
风险记录管理（5709 条）  每次命中的明细流水
  卡号/规则/发生时间/风险状态/设备ID/处理结果
       │
       │ 按 (卡号+规则) 聚合累计（旧后端自动，推断）
       ▼
灰名单管理（1821 条）    按卡+规则累计的只读台账
  发生次数/最后发生时间
       │
       │ 达阈值 / 人工审批（推断）
       ▼
黑名单管理（339 条）     带审批状态的拦截名单
```

### 关系要点

1. **风险规则 ↔ 风险组：多对多，靠勾选绑定**
   - 风险组表单页（`riskRuleGroup/form?riskRuleGroupId=xxx`）下方有一个规则列表，每条规则一个 `items` checkbox。
   - 实测绑定：
     - **风险组2**（`1001338411258368000`）：勾选 000008、000001、000002、000003、000006（5 条）
     - **风险组1**（`1001338326290157568`）：勾选 000008、000001、000002（3 条）
   - 同一规则可属于多个组（000008/000001/000002 两组都勾），同一组含多条规则 → 多对多。

2. **风险规则 = 定义层**：规则ID（`000001`~`000009`，缺 `000004`）、名称、描述、风险等级（1/3）、最大值（`riskRuleLimitValue`，如 300/99/35/10/1）。描述里写明业务后果，如「累计达到 10 次进入灰名单」「超过此数量列入黑名单」「永久禁用本产品」。

3. **风险记录 = 明细流水层**：每次规则命中写一条，含逻辑卡号（`userId`）、规则ID（`rsikRuleId`，注意旧系统字段拼写是 `rsik`）、规则名称/描述/等级、风险发生时间、风险状态（`rsikStatus`，样本均为 0）、设备ID（`riskDeviceId`）、入库/处理时间。

4. **灰名单 = 聚合台账层**：按 (卡号 + 规则名称) 聚合，记录发生次数（`riskRuleIdTimes`）与最后发生时间（`riskOccursLastDate`）。由风险记录累计而来（**推断**，旧后端代码本仓不可见）。

5. **黑名单 = 执行拦截层**：带审批状态（0 待审批 / 1 已审批 / 2 已停用），详情页可调 `updateStatus` 加入/移除，返回码含「已达拉黑上限永久禁用」。

> ⚠️ 除「规则↔组勾选绑定」为页面实证外，「记录→灰名单→黑名单」的自动流转阈值均为**推断**，旧后端逻辑不在本仓，需业主/旧系统维护方确认（同 `旧灰名单功能梳理.md` §1 的口径）。

## 二、导出文件清单

| 文件 | 内容 | 记录数 |
|---|---|---|
| `01_风险规则_全量.json` / `.csv` | 风险规则全量（字段：规则ID/名称/描述/等级/最大值/管理编码/入库时间） | 8（全量） |
| `02_风险组_全量.json` / `.csv` | 风险组全量，**含每组勾选的规则ID**（本次浏览器实扫新增字段） | 2（全量） |
| `03_风险记录_示例5条.json` / `.csv` | 风险记录示例（旧系统共 5709 条，此处取前 5 条） | 5（示例） |

- CSV 均为 UTF-8 BOM，可直接 Excel 打开。
- JSON 保留接口原始字段；风险组的「勾选规则」为表单页 checkbox 实扫结果，非 `listData` 原始字段。

## 四、口径

- 全程**只读导出**，未对旧系统做任何写操作。
- 数据含真实卡号，属生产规模数据，仅在测试/分析环境内使用，NEVER 外传。
