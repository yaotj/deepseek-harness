1. **扣款记录异常类型字典是 7 值**（含「正常」「双段计费正常订单_行程超时」「进站免检」），比交易管理单边查询页的 5 值多；与超时处理的 `ORDER_EXP_TYPE=5` 可能撞号，需求 FR-5.2 已标 MUST 核对。
