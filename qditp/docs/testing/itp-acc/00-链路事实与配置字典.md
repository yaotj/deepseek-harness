# ITP-ACC · 链路事实与配置字典

来源：仓库代码实测（2026-09-07，`8e8b7bd`）。只记录代码中确实存在的事实。

## 参数文件格式（para-server）

布局：`文件头(22B) + 正文 + MD5(16B)`。MD5 对「文件除末尾 16 字节」计算。
取证：`RowNetworkParser.java:27-57`、`:169-182`（四个 Parser 结构相同）

文件头 22 字节定长（`ParaFileImportService.readHeader:77-97`）：

- `fileType` 1B
- `fileCreateDateTime` 7B BCD
- `fileVerNo` 1B
- `paraType` 2B 小端
- `paraVerNo` 4B 小端
- `validDateTime` 7B BCD

中文字段用 **GB2312** 解码（`ParaFileReadUtils.java:10`、`:68-77`），不是 UTF-8。

参数类型 `paraType`（`ParaFileImportService.java:57-72`）：

- `0001` 路网拓扑 → `RowNetworkImportService`
- `0002` 日历 → `CalendarImportService`
- `0003` 车票 → `TicketImportService`
- `0004` 费率 → `RateImportService`
- 其他 → 抛 `暂不支持的参数文件类型: <paraType>`

**文件名约束**：必须以 `PRM.` 开头，否则跳过（目录扫描 `ParaImportController.java:85-89`）或抛 `参数文件名必须以 PRM. 开头`（上传 `:112-114`）。

## 版本表 `TBL_PARA_VERSION`

DDL：`para-server/src/main/resources/sql/para-schema.sql`
列：`PARA_TYPE`（主键）/ `CURRENT_VER_NO` / `CURRENT_FILE_NAME` / `VALID_DATE_TIME` / `MD5_VALUE` / `LAST_UPD_USER` / `LAST_UPD_TMS`
写入：`MERGE INTO` 式 upsert（`ParaVersionMapper.xml:21-48`）
Mapper 只有 `selectByParaType` 与 `upsert` 两个方法 —— **没有降级/回退方法**。

业务参数表首列均为 `PARA_VER_NO`（`TBL_LINE_INFO` / `TBL_STATION_INFO` / `TBL_TSF_INFO` / `TBL_ZONE_INFO` / `TBL_ZONE_DTL` / `TBL_SECT_INFO` / `TBL_SPECIAL_DATE` / `TBL_TIME_INTERVAL` / `TBL_FARE_TIME` / `TBL_CHIP_TYPE` / `TBL_TICKET_TYPE` / `TBL_TOTAL_SALE_PART` / `TBL_ADD_PARA` / `TBL_BASE_FARE` / `TBL_FARE_MATRIX` / `TBL_TICKET_FARE` / `TBL_FARE_GROUP`）。历史版本数据不删除，只前移 `TBL_PARA_VERSION` 的当前版本指针。

## 参数「热生效」机制

不是热加载，也没有缓存。每条查询 SQL 用子查询实时取当前版本：

```
WHERE PARA_VER_NO = (SELECT CURRENT_VER_NO FROM TBL_PARA_VERSION WHERE PARA_TYPE = '0001')
```

取证：`AppParaQueryMapper.xml:14-16`、`:35-37`、`:51-53`、`:65-67`、`:79-81`、`:97-99`、`:110-112`
因此导入事务一提交，下一个请求即读到新版本，**确实无需重启**——但机制是「每次查库 + 版本子查询」，不是「服务热加载参数」。

参数表只有 para-server 读写，其他模块全走 `rpc` 的 `ParaClient`（`service.para.url`，默认 `http://127.0.0.1:9107`，`ParaClient.java:33`），所以不存在多副本参数不一致的问题。

消费方调用点（均为请求内同步调用，无预加载、无本地缓存）：

- `ticket-server`：`TransStationNameResolver.java:45`、`TicketRideStatusServiceImpl.java:249`、`ExcessFareHandler.java:191`、`CardDataHandler.java:92/99/427/554`
- `fep-dev-server`：`GateTransactionHandler.java:305`（失败只 `log.warn` 返回 null，`:306-307`）
- `gate-txn-pay-server`：`GateTxnPayServiceImpl.java:624`
- `alipay-pay-sign-server`：`IndustryDetailEnricher.java:58`
- `fep-app-server`：`ParaAppServiceImpl.java:26-47`（纯转发 5 个 APP 接口）

版本对外暴露：`requestLineStationCodeVersion` 读 `0001` 行，把**同一个 `CURRENT_VER_NO` 同时作为线路版本与车站版本返回**，`changeDate` 取文件头 `validDateTime`（`AppParaServiceImpl.java:136-153`）。APP 据此自行决定是否重拉，属客户端拉取式刷新。

## FTP 配置（两台不同的服务器，勿混）

### A. 参数文件 FTP（para-server，2026-09-08 新增）

`@ConfigurationProperties(prefix = "para.ftp")`，`para/config/ParaFtpProperties.java`；值在 `para-server/src/main/resources/application.properties`。
键名：`para.ftp.ip` / `para.ftp.port` / `para.ftp.username` / `para.ftp.password` / `para.ftp.remote-dir` / `para.ftp.connect-timeout-millis` / `para.ftp.data-timeout-millis`
环境变量：`PARA_FTP_IP` / `PARA_FTP_PORT` / `PARA_FTP_USERNAME` / `PARA_FTP_PASSWORD` / `PARA_FTP_REMOTE_DIR`（口令走 K8s Secret，默认值为空）

- 地址 `172.20.214.101:21`，明文 FTP，被动模式，远端目录 `/parameter/cur/`（2026-09-08 实测；甲方口述的 `/parameter/cur/97000000/` 不存在）
- 只下载不上传：`ParaFtpScanService.scanAndImport()` 列目录 → 版本预筛 → 下载到 `Files.createTempDirectory("para-ftp-")` → 解析入库 → 删临时文件
- 文件名正则 `^PRM\.(0001|0004)\.(\d{4})\.(\d{6})(?:\.\d+)?$`（`ParaFtpScanService.java:40`）
- 详见 [[01-参数管理]]

### B. 编码设备 FTP（acc-es-server）

`@ConfigurationProperties(prefix = "ftp")`，`FtpComponent.java:11-32`；值在 `acc-es-server/src/main/resources/application.properties:27-35`。
键名：`ftp.ip` / `ftp.port` / `ftp.username` / `ftp.password` / `ftp.report-target-dir` / `ftp.report-local-dir` / `ftp.excel-dir` / `ftp.custom-local-dir` / `ftp.custom-target-dir`

传输方向与用途：

- 下载并定长解析编码设备报告文件：`EsReportServiceImpl.java:98-102`（`analysisFile`，解析 `:108-198`）、`:236-240`（`analysisCustomFile`，解析 `:245-329`）
- 上传个性化任务文件：`EsTaskServiceImpl.java:369-371`（`customFile`）

文件名：上传件为 `"9060" + esCode + 8位taskNo`（`EsTaskServiceImpl.java:339`，前缀常量 `CUSTOM_PER_FIX` 在 `:36`）；Netty 应答里同名下发给设备（`BusinessHandler.java:332`）。下载件的文件名**不由 ITP 生成**，来自设备 7004 报文体的定长 20 字节字段（`EsTaskReport.java:95-97`，偏移按任务类型为 `88`/`94`/`114`）。

⚠️ 与参数无关：这条 FTP 只传编码设备任务与报告文件，**不传参数文件、不传逻辑卡号文件**。

⚠️ **两组配置键前缀必须区分**：`para.ftp.*` / `PARA_FTP_*` 是参数文件服务器，`ftp.*` / `FTP_*` 是编码设备服务器。同名会串，部署与测试时都要核对。
