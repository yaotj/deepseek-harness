## 编写约束

- **只记录代码中确实存在的事实，均带 `文件:行号`；找不到的写「未找到」，NEVER 推断、NEVER 编造 URL / 表名 / 列名 / 状态取值。**
  本目录刻意保留了若干 `select * from X where 1 = 0;` 形式的**占位 SQL** —— 那表示「表名已核实、列名未核实」，
  用前 MUST 去对应 DDL 行号核对。**NEVER 把占位 SQL 改成猜出来的列名。**
- **NodePort 一律写「待现查 `kubectl get svc -n itp`」**：本轮未执行 `kubectl`，
  且 `AGENTS.md` §7 明确「集群版本号与端口 MUST 每次现查、NEVER 引用文档里记的数字」。
- 预期结果 = **可在接口响应 / 库表行 / 日志里核对的断言**；纯 UI / 真机动作标「需人工」，但仍给等价 curl 入口。
- 矛盾显式标 ⚠️，**不擅自裁决**，统一收敛到 `05`，按影响排序。
- 执行结果回填在各用例的「结果：（待回填）」行，**不改写链路事实段落**；链路事实与代码不符时 MUST 整段改写并注明作废日期。
- **本目录不生成「实现率 / 进度百分比」类汇总**（`AGENTS.md` §5.3 明令禁止）。判断某接口是否存在，直接看 Controller 的映射注解。
