## 一、对账文件

### 1.1 单边交易明细文件
| 属性 | 值 |
|------|-----|
| 文件名格式 | `ITP.EXP.yyyyMMdd` |
| 生成时间 | T日2点统计T-2日2点至T-1日2点的单边明细 |
| 存放路径 | 指定FTP服务器 |
| 示例 | 8月20号2点生成文件名为"ITP.EXP.20190818" |

**文件数据格式**（管道符分隔）：
```
'逻辑卡号'|'票卡交易序列号'|'订单金额（单位分）'|'实际扣款金额(单位分)'|'优惠金额'|'进站设备编码'|'进站时间'|'出站处理设备类型'|'出站设备编码'|'出站时间'|'订单异常类型'|'支付方式'|'交易日期'
```

**订单异常类型说明**：
| 代码 | 说明 |
|------|------|
| 1 | 单边账(入站) |
| 2 | 单边账(出站) |
| 3 | 单边入站(人工处理单) |
| 4 | 单边出站(人工处理单) |
| 5 | 乘客自主补进站 |
| 6 | 乘客自主补出站 |
| 7 | TVM补币找零不足 |
| 8 | TVM卡票 |
| 9 | TVM/BOM发售无效票 |
| 10 | 闸门无用 |
| 11 | 无票出闸 |
| 12 | 人为单程票无效 |
| 13 | 非人为单程票无效 |
| 14 | 储值票无效 |
| 15 | 其他情况 |

### 1.4 虚拟电子多日计次票对账文件
| 属性 | 值 |
|------|-----|
| 文件名格式 | `ITP.DETAIL.YYYYMMDD` |
| 存放路径 | `/itp/recon/` |
| 测试环境 | ip:172.20.215.1 port:21 username:ftpuser password:ftpuser |

**文件数据格式**（逗号分隔）：
```
运营日期,交易类型,逻辑卡号,交易日期时间,交易金额,当前车站名称,设备编码
```

**说明**：
- 车票购买的交易：交易类型为"发售"，当前车站类型和设备编码传空
- 超时的行程：类型为"出站"，费用为线网最高票价或1
- 虚拟电子多日计次票的交易金额传0
- 只对车票购买和超时费用进行对账

## 四、逻辑卡号文件

### 4.1 逻辑卡号文件
| 属性 | 值 |
|------|-----|
| 文件路径 | `/itp/qrLoigcNum/` |
| 文件传输方向 | ACC → ITP |
| 文件格式 | 逻辑卡号+空格+票卡类型 |
| 文件名示例 | `0426081004.txt` |

### 4.2 逻辑卡号请求接口

#### 接口信息
| 属性 | 值 |
|------|-----|
| 接口名称 | 根据票卡类型请求逻辑卡号 |
| 接口编号 | IF8A-xx |
| 接口地址 | `http://[ip]:[port]/[project]/ci/itp/requestQrLoigcNumList` |
| HTTP方法 | POST |

#### 接口说明
为了ACC能够使用逻辑卡号区分虚拟多日计次票、普通二维码、NFC车票、员工票，申请逻辑卡号时虚拟多日计次票与员工卡传不同的类型。

#### 请求参数
| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | RequestNum | string | 请求数量 默认10万 |
| 2 | RequestSeq | String | 请求批次号 |
| 3 | ticketType | String | 车票类型 |

**ticketType 车票类型定义**：
| 值 | 说明 |
|----|------|
| 0x44 | 员工卡 |
| 0x45 | 一日票 |
| 0x46 | 三日票 |
| 0x47 | 计期票 |
| 0x48 | 计期计次票 |

#### 响应参数
| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | RetCode | string | 返回码 |
| 2 | RetMsg | string | 返回消息 |
| 3 | FileName | String | 文件名 |

#### 请求示例
```json
{
  "bizData": {
    "requestNum": "100000",
    "requestSeq": "1011070802",
    "ticketType": "41"
  }
}
```

附带参数：
```
charset=UTF-8&format=json&providerId=05&signType=02&timestamp=20180511135750
```

#### 响应示例
```json
{
  "retCode": "0000",
  "returnMsg": "执行成功。",
  "filename": "0426081004.txt"
}
```
