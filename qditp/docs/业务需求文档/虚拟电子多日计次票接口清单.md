### 1. IF5A-01 - 请求票卡分析

**接口路径**：`/ci/bom/requestCardDataAnalyse`
**HTTP方法**：POST
**接口说明**：BOM扫描二维码分析票卡信息，返回卡类型和剩余次数

**请求参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | providerId | String | 发行方代码 |
| 2 | msisdn | String | 手机号，预留 |
| 3 | cardId | String | 逻辑卡号 |
| 4 | updateType | String | 更新区域类型: 00=非付费区, 01=付费区 |

**响应参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | retCode | string | 返回码 |
| 2 | retMsg | string | 返回消息 |
| 3 | providerId | String | 发行方代码 |
| 4 | cardId | String | 逻辑卡号 |
| 5 | cardType | String | 卡类型: 00=后付费二维码, 11=员工票, 12=一日票, 13=三日票, 14=计期票, 15=计期计次票, 17=离线码 |
| 6 | remainTimes | String | 剩余次数 |

### 3. IF1A-04 - 查询票卡状态

**接口路径**：`/ci/agm/requestQrCodeStatus`

**请求参数**：

| 序号 | 字段名 | 类型 | 说明 |

| 2 | cardId | String | 逻辑卡号 |
| 3 | trxType | String | 交易类型: 01=进站, 02=出站 |
| 4 | ticketTransSeq | String | 交易计数器 |
| 5 | qrType | String | 二维码类型: 01=在线, 02=离线 |

**响应参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | retCode | String | 返回码 |
| 2 | retMsg | String | 返回消息 |
| 3 | itpUserId | String | ITP用户编码 |
| 4 | cardId | String | 逻辑卡号 |
| 5 | lastTicketStatus | String | 上次票卡状态: 02=补出站, 03=发售, 04=已进站, 05=已出站, 50=查询锁定, 51=车票重复使用 |
| 6 | lastHandleDateTime | String | 上次交易时间 |
