# 非现金购票单程票退款功能 - 接口清单

> 文档版本：V3
> 生成日期：2026-08-16
> 接口总数：2个

---

## 业务场景

**TVM非现金购票单程票在BOM进行退款**

场景说明：
- TVM购买单张及多张单程票
- 在BOM或智能客服处进行全部单程票或部分单程票退款

业务流程：
1. BOM读卡获取单程票逻辑卡号
2. BOM通过逻辑卡号查询该张车票发售时间最近的一笔订单
3. 查询应答中，若没有订单号，则表示现金购票；若有订单号，则返回相应信息
4. BOM拿到相应信息，向ITP发起单程票故障通知请求
5. ITP收到请求后，返回结果；后台通过订单号、车票张数、金额等信息判断，生成退款订单，并向支付平台发起退款

### 1. IF8A-xx - 单程票交易查询

**接口路径**：`/ci/bom/requestOrderResult`
**HTTP方法**：POST
**接口说明**：通过上传票卡逻辑号与交易日期，查询是否有存在该卡订单

**请求参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | ticketLogicNum | String | 票卡逻辑号 |
| 2 | transDate | String | 单程票交易日期 YYYYMMDDHHMMSS |

**响应参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | retCode | string | 返回码 |
| 2 | retMsg | string | 返回消息 |
| 3 | paymentResult | string | 查询结果: SUCCESS=成功, FAILED=失败 |
| 4 | paymentResultDesc | string | 支付结果描述: 无订单号等 |
| 5 | orderNo | String | 原订单号 |
| 6 | transDate | String | 交易日期 YYYYMMDDHHMMSS |
| 7 | transAmount | String | 单张车票交易金额：分 |
| 8 | paymentChannelCode | string | 支付通道编码 |

**请求示例**：

```json
{"ticketLogicNum":"0020180503110402","transDate":"20180503132702"}
```

**响应示例（成功）**：

```json
{"retCode":"0000","retMsg":"查询成功","paymentResult":"SUCCESS","paymentResultDesc":"查询成功","orderNo":"201805030000123456","transDate":"20180503132702","transAmount":"500","paymentChannelCode":"01"}
```

**响应示例（失败-无订单）**：

```json
{"retCode":"0000","retMsg":"查询成功","paymentResult":"FAILED","paymentResultDesc":"无订单号","orderNo":"","transDate":"","transAmount":"","paymentChannelCode":""}
```

### 2. IF8A-xx - 单程票原路退款

**接口路径**：`/ci/BOM/requestTicketRefund`
**HTTP方法**：POST
**接口说明**：BOM对单程票二维码退款时，发送单程票原路退款

**请求参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | orderNo | String | 订单号 |
| 2 | TakeTicketNum | string | 票数量 |
| 3 | ticketRefundDate | string | 退款时间 YYYYMMDDHH24mmss |
| 4 | ticketLogicNum | String | 票卡逻辑号 |
| 5 | transDate | String | 交易日期 YYYYMMDDHHMMSS |
| 6 | transAmount | String | 交易金额 |
| 7 | transType | String | 交易类型 06=单程票退款 |

**响应参数**：

| 序号 | 字段名 | 类型 | 说明 |
|------|--------|------|------|
| 1 | retCode | string | 返回码 |
| 2 | retMsg | string | 返回消息 |

**请求示例**：

```json
{"orderNo":"00201805031326111081","TakeTicketNum":"1","ticketRefundDate":"20260108113622","ticketLogicNum":"00161019010183A1","transDate":"20260108113015","transAmount":"500","transType":"06"}
```

**响应示例**：

```json
{"retCode":"0000","retMsg":"成功"}
```
