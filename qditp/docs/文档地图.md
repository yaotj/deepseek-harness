## 目录性质（三类，先建立）

`docs/` 下三类内容：
- **AI 提示词文档**（`business/` `domain/` `architecture/` `ops/` `设计/` `reviews/` `提示词/`）——**可改**。
- **甲方原始规格**（`接口规范文档/` `业务需求文档/` `技术规范文档/`）——**只读、只有 `.docx`/`.doc` 原文，NEVER 修改**；这些目录里 2026-08-25 前脚本抽取的派生产物（接口清单 `.md`/`.json`，接口数与源文档不符、部分源已不存在）已全删，**NEVER 再新增派生文件**。
- **外部系统接口规格**（`external/`）——**按供方版本整体替换**，不混入本项目实现说明。

## 逐目录

### `docs/提示词/`
**跨工具引导词**（`引导词.md`）：comate / trae 等无规则机制的工具开工前 **MUST 粘贴其正文**，并承担同样回写义务（AGENTS.md §5.2 第 5 步）。只放跨工具通用的硬约束，业务细节一律靠 `docs/business/` 按需读，**NEVER 把业务事实抄进引导词**。它**不是**第二份索引（目录索引以本文件为准）。

**任务路由表**（`任务路由表.md`）：**「任务 → 读哪篇」的唯一真源**（2026-10-20 从 `docs/ops/workflow-routes.md` 迁来——原位置与 `docs/ops/`「部署与配置清单」的目录语义不符，且它并不在 `docs/ops/README.md` 的文档清单里）。带 ★ 的 6 行是高频项，已内联在 `AGENTS.md` §5.1；**两表由 `lint-prompts.py` 校验路径集合完全一致**，漂移即 ERROR。改路由 MUST 改这两处（或只改路由表 + 同步 §5.1），**NEVER 让两个入口各说各话**。

**提示词工程与文档规范**（`工程与文档规范.md`）：提示词体系治理的细则（常驻 vs JIT 判据、否定约束配正向替代、提交前 lint 门禁、源码行号引用禁令），是**写 / 改任何 `.md` 提示词或文档时 MUST 先读**的文件。

### `docs/tracking/`
**问题跟踪索引与处理文档**：`问题清单.md` 是**全仓待跟踪问题的唯一索引**（含重档 / 轻档两档登记粒度，判据见 `AGENTS.md` §5.0「问题跟踪」），`IT-<编号>-<简述>.md` 是重档问题的处理文档（模板 `IT-模板.md`，固定 6 节）。**索引行 MUST 一眼读完**（一句话现象 + 状态 + 下一步 + 关联文档），处理过程只写在 IT 文档里，**NEVER 两处各写一份**。本目录不在 `lint-prompts.py` 的约束层范围内（属记录而非指挥层），但**过期引用仍会误导人**，引用时 MUST 现查。

### `docs/testing/`
**测试知识库**（索引 `README.md`）：按业务域归档的测试用例与链路事实字典（`user-card/` `daily-ticket/` `payment/` `face-pay/` `e-ticket/` `alipay-channel/` `bom-oneside/` `itp-acc/` `device-sle/` `admin-web/` `app/` `api-inventory/` `pay-sign/`），每域含 `INDEX.md` + 链路事实字典 + 用例页 + 阻塞项汇总。**执行记录带日期后缀，属当时快照**；判断现状 MUST 以 `docs/business/` 为准。本目录是**记录与执行层，不在 lint 约束层内**。

**领域边界与聚合归属**（索引 `README.md`）。比 `business/` 高一层：`business` 回答「怎么实现」，`domain` 回答「归谁管、边界在哪」。**调整表归属 / 拆库 / 评审外部架构方案 / 判断跨服务调用是否合理时 MUST 先读**。要点：六域划分与目标 Schema、四条边界自查判据（双向 RPC 即边界画错 / 1:N 子实体不能当父状态机的状态 / 热路径写入定 owner / 域内应能本地事务强一致）、对外契约判据（**能被 `parseBizData` 解析的 DTO 就是对外契约，NEVER 加字段**）；`state-machines.md`（五台在跑的状态机与「枚举 + 白名单 + CAS」，已决定不引 Spring Statemachine）；`outbox.md`（「落库状态 + 扫表补偿」模板，NEVER 抽公共 outbox 表——跨域、违反边界判据 3，见 ADR-D46；**与 `state-machines.md` 平级**：同管跨域状态模式——一个管状态迁移、一个管状态补偿投递，故留 `domain/` 而非 `architecture/`（那里只放单一工程机制陷阱）或 `ops/`（运维操作侧）**）；`decisions.md`（ADR 与**撤回记录**，撤回记录 NEVER 删）。**追加新 ADR 前 MUST 用 `grep -n '^#\{2,3\} ADR-D'` 查已用编号，NEVER 只匹配 `^## `**（文件有 `###` 级 ADR，只查二级标题会把已占用号判成空号）。
