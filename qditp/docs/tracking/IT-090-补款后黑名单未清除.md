# IT-090: 补款后黑名单未清除

## 背景
用户 `17625926347` 补款成功后，APP 首页仍显示"0次未扣费订单，刷新后可正常乘车"，说明黑名单未清除。

## 根因
`BlacklistChannelSyncService.deliverReleaseRow()` 对所有渠道的黑名单记录都调用 `alipayBlacklistNotifyPort.notifyBlackListChange()`，但：
- `channelCode='01'`（地铁App）的记录应该通过 HCE 文件同步到闸机，无需实时通知支付宝
- `channelCode='02'`（支付宝）的记录才需要通知支付宝

当支付宝服务不可达时（测试环境），所有 `channelCode='01'` 的解黑通知都失败了，导致黑名单停留在 `RELEASING + FAILED` 状态。

## 修复方案
在 `deliverReleaseRow()` 中增加渠道判断：
- `channelCode='01'`（地铁App）：直接完成解黑收口，跳过支付宝通知
- `channelCode='02'`（支付宝）：保持原有逻辑，调用支付宝通知接口

- `blacklist-server/src/main/java/com/chinasofti/huateng/blacklist/service/impl/BlacklistChannelSyncService.java`
