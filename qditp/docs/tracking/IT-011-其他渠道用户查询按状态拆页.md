# IT-011 其他渠道用户查询按状态拆页（有效 / 已注销）

> 本处理文档对应 `docs/tracking/问题清单.md` 索引表中 `IT-011` 一行。

## 1. 背景 / 现象

- **发现时间**：2026-10-16。
- **发现渠道**：业主主动提出需求。
- **影响范围**：综管台「用户管理 → 其他渠道用户查询」页（`trans/user/itp/index.vue`），后端数据源为 `account-server` 的 `USER_ITP_REG_INFO`。
- **现象描述**：
  - 该页已有「注册状态」列（有效 / 已注销），但**没有状态筛选条件**；
  - 业主希望对「所有卡号」按有效/失效做状态管理，并建议**拆成两个界面**：原页查有效、新增「已注销用户查询」页查已注销；
  - 同时澄清：注销是逻辑删除（`DEL_YN=0`），记录仍在 `USER_ITP_REG_INFO`，并非立即物理删除；
    物理删除（归档）由 `AccountArchiveService.archiveIfLastChannelRemoved` 执行。
  - **2026-10-16 追加规则**：IF8A-42 APP 销户新增三道前置校验，**全部满足才允许注销**（account-server **2.0.83**，ADR-D172）：
    1. 无未结清订单（`GATE_TXN_PAY` 的 `unpaidCount + failureCount = 0`，已有校验）；
    2. 无欠费（同上 `failureCount`，归入口径 1）；
    3. 所有签约支付通道已解绑（`APP_USER_PAY_CHANNEL` 计数为 0，新增校验，错误码 `8025`）。
  - 由于通道必须在注销前清空，注销成功后 `tryArchiveAfterCancel` 会**立即触发归档**（物理删除），
    因此「已注销用户查询」页若继续查 `USER_ITP_REG_INFO.DEL_YN=0` 将永远为空；
    **已改为方案 C：该页改查 `USER_ITP_REG_LOG` 的销户记录（`OPER_TYPE=2`）**，覆盖已物理归档的行。

## 2. 根因分析

- 这不是缺陷，而是**查询能力缺失**：后端 `/page/user/itp/search` 原实现通过 `selectListByThirdUserId` / `Msisdn` / `CardId` 查询时**不带 `DEL_YN` 过滤**，返回有效与已注销的混合结果；
- 前端表格靠「注册状态」列人工辨认，无法快速按状态聚焦；
- 操作列中的「签约渠道」按钮对非有效记录本身已禁用，但页面没有按状态拆分入口，运维体验不佳。

## 3. 方案对比

| 方案 | 思路 | 优点 | 缺点 | 风险 |
|------|------|------|------|------|
| 方案A：原页加状态下拉 | 在现有「其他渠道用户查询」页增加「全部 / 有效 / 已注销」下拉筛选 | 改动最小，一个入口 | 筛选态下操作列按钮语义不一致；已注销行仍显示「签约渠道」等按钮 | 低 |
| 方案B：拆成两个独立页面 | 原页固定只查有效，新增「已注销用户查询」页固定只查已注销 | 职责清晰、入口直观、已注销页可隐藏不适用操作 | 需新增菜单与组件 | 低 |

## 4. 决策与结论

- **选定方案**：方案B（拆页）。
- **决策理由**：业主原话即建议「分为两个界面进行查询」，且已注销用户通常只做查看、不做操作，独立页面可隐藏操作列，避免误操作。
- **设计问询结果**（4 项）：
  1. 落点：`trans/user/itp/index.vue`（其他渠道用户查询页）；
  2. 拆分：原页只查有效 + 新页只查已注销；
  3. 状态文案：「有效 / 已注销」（与现有表格列保持一致）；
  4. 状态管理范围：**只读查询**，不在页面提供注销/恢复按钮。
- **影响范围 / 关联模块**：
  - `account-server`：`ItpUserSearchQuery`、`ItpUserPageController`、`ItpUserQueryService`、新增 `ItpUserCanceledSearchView`、
    `UserItpRegInfoMapper`、`UserItpRegLogMapper`；
  - `web`：`trans/user/itp/index.vue`、新增 `trans/user/itp-canceled/index.vue`、可复用组件 `trans/user/components/ItpUserSearchPanel.vue`、
    `web/src/api/trans/userSearch.js`；
  - `web-server/sql/itp-canceled-user-menu.sql`：新增菜单（`parent_id=2071`，perms=`trans:user:itp-canceled:query`）。
