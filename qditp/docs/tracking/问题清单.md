### IT-051: gate-txn-pay-server 补扣重试队列 ORA-00933 SQL 语法错误

**现象**: 每 1 分钟执行 `/internal/gate-txn-pay/retry-queue/consume` 时报 `ORA-00933: SQL command not properly ended`
**根因**: `GateRetryQueueMapper.xml` 的 `recoverTimeout` 使用了 `INTERVAL ? MINUTE` 动态参数写法，Oracle 不支持；另 `batchInsertIgnoreDuplicate` 中 `TXX_DATE` 拼写错误（应为 `TXN_DATE`）
**修复**: 已改 `NUMTODSINTERVAL(#{timeoutMinutes}, 'MINUTE')`，修正 `TXX_DATE` → `TXN_DATE`；编译通过
**状态**: 已修复，待发版验证
