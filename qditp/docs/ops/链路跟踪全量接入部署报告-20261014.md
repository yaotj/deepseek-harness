### INFO/DEBUG 日志进入 VictoriaLogs

为满足链路跟踪细节检索需求，调整共享日志配置：

- `resource/micro/web/src/main/resources/log4j2-linux.xml`
  - `VictoriaLogs` appender 的 `ThresholdFilter` 从 `WARN` 改为 `DEBUG`。
  - `com.chinasofti.huateng` logger 级别从 `${webLoggerLevel}`（INFO）改为 `DEBUG`；其 `RollingFile`/`Console` `AppenderRef` 加 `level="INFO"` 兜底，避免本地 DEBUG 日志爆炸。
  - `VLOGS` logger 级别从 `INFO` 改为 `DEBUG`，同样对本地 appender 做 INFO 兜底。

- `resource/micro/web/pom.xml`：共享配置变更，`web` artifact 版本从 `2.0` 升至 `2.1`。

- 12 个模块 `pom.xml`：各自末位版本 +1，并将 `<web.version>` 从 `2.0` 更新为 `2.1`。

### 503 问题根因与修复

4 个 503 模块均与本次 tracing 配置改动无关，属于测试环境既有配置问题。根因是 **K8s Deployment 中的 dot-name 环境变量（如 `server.port`、`other.sql.host`）未被 Spring Boot relaxed binding 识别**，导致应用使用了 application.properties 中的默认值，进而出现端口 / 数据库地址错配。

| 模块 | 根因 | 修复操作 |
|------|------|----------|
| fep-dev-server | Deployment 无 `containerPort`；`server.port=8080` env 未生效，应用实际监听 9104，Service targetPort 错配。 | Service targetPort 改为 9104；Deployment 增加 `containerPort: 9104`；YAML 中 `server.port` 改为 9104。 |
| account | `other.sql.host`/`other.sql.database` 等 dot-name env 未生效，DB URL 落到 `orcl`。 | 追加 `DB_HOST`/`DB_NAME`/`DB_USERNAME`/`DB_PASSWORD` 下划线命名 env；同步修改源码 application.properties 默认值为正确地址。 |
| blacklist-server | 同 account；且 `server.port=8080` env 未生效，应用监听 9102，Service targetPort 8080 错配。 | 追加 DB_* env；Service targetPort 改为 9102；Deployment 增加 `containerPort: 9102`；YAML 中 `server.port` 改为 9102；同步修改源码默认值。 |
| para-server | `server.port=8080` env 未生效，应用监听 9107，Service targetPort 8080 错配；DB 连接一度异常。 | Service targetPort 改为 9107；Deployment 增加 `containerPort: 9107`；YAML 中 `server.port` 改为 9107；追加 DB_* env。 |
| ticket-server | Service targetPort 为 9103，但 Deployment 中 `server.port=9100` env 生效，应用实际监听 9100，导致 targetPort 错配。 | Service targetPort 改为 9100，与 Deployment env 保持一致。 |
| alipay-pay-sign-server | 镜像构建过程中 `AlipayPayCallbackLog.class` 字节码损坏（`Invalid method Code length 0`），应用启动失败；且 `other.sql.host` 缺少 `:1521`、未配置 DB_* 下划线命名 env。 | 重新 clean 构建并推送镜像；追加 `DB_HOST`/`DB_NAME`/`DB_USERNAME`/`DB_PASSWORD`；修正 `other.sql.host=172.20.222.3:1521`。 |
