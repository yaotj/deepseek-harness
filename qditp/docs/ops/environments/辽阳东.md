## 入向路由分发（fep-app-vr）

> 状态：**规划阶段，本节全部「待录入」，只预置结构；上线时整段替换为实测值。**
> 结构必须与测试环境同构（7 exact + 8 prefix + `/itptvm/` `/itpbom/` 两条保留前缀 rewrite + SCG 前置），差异只在各落点 Service 名 / 端口 / SCG 地址 / 公网入口。

### 待录入项（MUST 上线前补全，参照现查方法）

| 项 | 现值 | 现查方法 |
|---|---|---|
| 入向公网入口 / 回调 URL | 待定（MUST 换辽阳东自己的公网映射 + 通知支付中心 / 支付宝 / APP / 设备侧改对端） | `kubectl get vs fep-app-vr -n itp -o yaml` |
| `fep-app-vr` 15 条路由 | 结构同测试环境（7 exact SCG + 8 prefix），**Service 名 / 端口 MUST 现查重录** | 同上 |
| 7 条 SCG exact 落点 | 结构同上，destination = 辽阳东 `route-sentinel-svc:8080`（**已拍板：SCG 在辽阳东必部署，7 条 exact 恒指 route-sentinel，NEVER 指 face-pay**） | 同上 |
| `route-sentinel` 内部路由 | `legacy-route` URI 指辽阳东 face-pay 端点（现查）；`face-pay-split-route` D11 占位 | `curl .../actuator/gatewayroutes` |

### 上线时固定动作（与测试 / 红岛一致，NEVER 省略）

- 7 条 exact MUST 排在 `/itptvm/` `/itpbom/` 两条前缀**之前**，否则前缀先命中、SCG 收不到流量。
- `/itptvm/`、`/itpbom/` 两条 rewrite **保留前缀**，其余 6 条 rewrite `/`；改路由 NEVER 顺手改 rewrite。
- SCG 自身故障回滚 = 把 7 条 exact 指回 face-pay（或删掉由前缀兜底），其余端点不受影响。
- **NEVER 把测试 / 红岛的 Service 名、NodePort、DB / HSM 地址抄到辽阳东**（见本文「上线硬约束」）。
