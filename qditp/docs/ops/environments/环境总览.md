# 环境总览

> 本目录按环境拆分维护 qd-itp 的 4 个运行环境。

| 环境 | 类型 | 状态 | 说明 |
|---|---|---|---|
| 本地开发 | dev | 在用 | 开发者本机 / 本地 Docker |
| 测试环境 | test | 在用 | 当前对接新华三（H3C）底座，ns `itp`（k8s-master） |
| 红岛 | 生产 | 已部署（联调中） | 生产站点之一；24 个 Deployment 在 `itpb` 运行，本机经 `hd-linux` 可达 |
| 辽阳东 | 生产 | 待部署 | 生产站点之一，与红岛同为生产、部署方式相同 |

## 各环境文档

- [本地开发.md](本地开发.md) — 开发者本机 / 本地 Docker
- [测试环境.md](测试环境.md) — 测试环境（k8s-master / 172.20.211.23）
- [红岛.md](红岛.md) — 红岛生产站点（前端/VL 已部署、业务待部署）
- [辽阳东.md](辽阳东.md) — 辽阳东生产站点（规划阶段）
- [网络路由配置.md](网络路由配置.md) — **本机**通过 USB 网卡接入各环境内网的地址 + 网段路由配法；含**红岛网段分区、各段网关与端点可达性实测**（源：ACLC 红岛数据中心设备管理表）

> **注意区分两种「路由」**：本节及下文提到的「路由」若无特别说明，指 **Istio 入向路由分发（`fep-app-vr`）**；
> **本机操作系统层面**访问内网的网段路由见 [网络路由配置.md](网络路由配置.md)，两者互不相干、NEVER 混谈。

> **入向路由分发（`fep-app-vr` 15 条：7 SCG exact + 8 prefix）按环境各落一份**，
> 结构同构、落点 / 端口 / 公网入口各异，**MUST 现查、NEVER 跨环境抄值**：
> - 测试环境：[测试环境.md](测试环境.md)「入向路由分发」节（唯一在用，实测值）
> - 红岛：[红岛.md](红岛.md)「入向路由分发」节（待业务上线补全）
> - 辽阳东：[辽阳东.md](辽阳东.md)「入向路由分发」节（规划阶段占位）
> - 切换 / patch 操作流程统一走 `docs/ops/流量切换Runbook.md`。
