## 〇、生产红线（动手前必读）

- **二次确认 + 灰度 / 回滚预案**：生产发布 MUST 二次确认（AGENTS.md §5.C），单副本模块逐个滚更，不做金丝雀分流。
- **NEVER 混用测试值**：以下测试 / 其它环境值**严禁**带入红岛生产——
  - 测试 k8s-master `172.20.211.23:30xxx`（deploy 里的 `service.*.url` 覆盖值）
  - 测试库 `172.20.222.3:1521/AFCITPDB`（collect-pay / face-pay / employee-card-acc-simulator 默认）
  - 测试 VLOGS `victoria-logs-pbi6a-svc.itp.svc:30032`
- **升版本末位 +0.0.1**，NEVER 同 tag 覆盖；rollout 后 MUST 比对 Pod imageID 与推送 digest。
- **红岛网络隔离**：本机 TCP 被红岛防火墙拦截；拉集群实况须把 USB 网卡（AX88179B）换插到对应区口（K8s 控制区 `172.120.2.x` / 业务区 `172.120.110.x`）或走堡垒机，**不可臆造红岛 IP**。
