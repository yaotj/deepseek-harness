# IF8A-04 基于 codeStatus 的补进出站规则

> 本文档整理基于 codeStatus 的自助补站规则。

## 1. 核心字段定义

| 字段 | 代码 | 含义 |
|------|------|------|
| **车票状态 (CODE_STATUS)** | `02` | 结束行程 |
| | `03` | SJT 发售（init 2）/ 默认状态 |
| | `04` | 已进站（entry） |
| | `05` | 已出站（exit） |
| | `06` | 超时出站 |
| | `08` | 20分钟内免费更新（BOM非付费区） |
| | `09` | 20分钟内付费更新（BOM非付费区） |
| | `10` | 入站码更新（BOM付费区） |
| | `80` | 用户自助补出站 |
| | `81` | 用户自助补进站 |

## 2. 补进出站规则全景表

### 2.1 结束行程 (CODE_STATUS = 02)

| 允许补站类型 | 说明 |
|-------------|------|
| 01（补进站） | 可能是跟随进站，允许补进站 |

### 2.2 新卡/初始状态 (CODE_STATUS = 03)

| 允许补站类型 | 说明 |
|-------------|------|
| 01（补进站） | 新卡需补进站 |

### 2.3 已进站状态 (CODE_STATUS = 04)

| 允许补站类型 | 说明 |
|-------------|------|
| 02/03/04（补出站） | 已进站需补出站，可能是跟随出站 |

### 2.4 已出站状态 (CODE_STATUS = 05)

| 允许补站类型 | 说明 |
|-------------|------|
| 01（补进站） | 已出站需补进站 |

### 2.5 超时出站 (CODE_STATUS = 06)

| 允许补站类型 | 说明 |
|-------------|------|
| 01（补进站） | 超时出站后需补进站 |

### 2.6 20分钟内免费更新 (CODE_STATUS = 08)

| 处理方式 | 说明 |
|----------|------|
| 提示用户到服务台 | 不支持手动补进出站 |

### 2.7 20分钟内付费更新 (CODE_STATUS = 09)

| 处理方式 | 说明 |
|----------|------|
| 提示用户到服务台 | 不支持手动补进出站 |

### 2.8 入站码更新 (CODE_STATUS = 10)

| 处理方式 | 说明 |
|----------|------|
| 提示用户到服务台 | 不支持手动补进出站 |

### 2.9 用户自助补出站 (CODE_STATUS = 80)

| 允许补站类型 | 说明 |
|-------------|------|
| 01（补进站） | 用户自助补出站后需补进站 |

### 2.10 用户自助补进站 (CODE_STATUS = 81)

| 允许补站类型 | 说明 |
|-------------|------|
| 02/03/04（补出站） | 用户自助补进站后需补出站 |

## 3. 补站类型映射

| upgradeAreaType | 含义 | 对应允许的 codeStatus |
|-----------------|------|----------------------|
| 00 | 无需更新 | 无 |
| 01 | 补进站 | 02/03/05/06/80 |
| 02 | 补出站 | 04/81 |
| 03 | 20分免费更新 | 不支持自助补站 |
| 04 | 20分付费更新 | 不支持自助补站 |

## 4. 特殊说明

- 无需 FFFFF 校验：所有补站操作均不检查 gateInStation / lastTxnStation 是否为 FFFFF
- 08/09/10 状态：当前不支持自助补站，需引导用户到服务台处理
- 02 状态：虽然行程已结束，但考虑到可能是跟随进站场景，允许补进站
