1. 支付结果通知请求参数信息

|  |  |  |
| --- | --- | --- |
| 字段 | 类型 | 说明 |
| userId | string | 用户编码 |
| orderNo | string | 订单号 |
| tradeNo | string | 支付交易流水号 |
| payResult | string | SUCCESS/FAIL |
| payAmount | string | 支付金额 |
| payDate | string | 支付时间 |
| voucher | string | 取票凭证 整段用于生成二维码  预留字段 |
| orderType | String | 订单类型  单程票0  普通日票1  全城通日票2 |
