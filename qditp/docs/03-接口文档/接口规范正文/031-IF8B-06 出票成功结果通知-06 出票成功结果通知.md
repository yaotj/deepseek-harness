# IF8B-06 出票成功结果通知

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/app/receiveTakeTicketResult
```

## 接口说明

当面付出票结果通知

## 请求参数

参数详情参见规范表 65。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | string | 第三方用户id |
| cardId | String | 地铁会员卡号 |
| cardType | String | 2.8	卡类型编码 |
| blackListType | String | 解约结果
1：加入黑名单
2：移除黑名单 |
| optionDate | String | 操作时间时间, 格式如：
YYYYMMDDHH24mmss |
| expireTime | String | 黑名单有效期, 格式如：
YYYYMMDDHH24mmss。
当解约结果为1时有效 |

## 应答参数

参数详情参见规范表 66。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
