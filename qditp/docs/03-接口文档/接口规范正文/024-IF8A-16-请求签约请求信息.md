# IF8A-16 请求签约请求信息

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

`https://api.mch.weixin.qq.com/papay/entrustweb?appid=wx426a3015555a46be&contract_code=122&contract_display_account=name1……`

## 请求参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| thirdUserId | string | 第三方用户编码 |
| requestSignSeq | string | 签约请求流水号 |
| paymentVendor | string | 支付类型 03 支付宝 04 微信支付 06 建行龙支付 07 银联云闪付 0B 钱包支付 |

## 应答参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
