# IF8A-19 BLE通知闸机检票通知

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

`http//:[ip]:[port]/[project]/ci/app/notiAgmVerifyResult`

## 请求参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| thirdUserId | String | 第三方用户id |
| cardId | String | 地铁会员卡号 |
| cardType | String | 2.8	卡类型编码 |
| channel | String | 2.7	支付通道编码 |

## 应答参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
