# if8a_62– 日票支付结果查询

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/payment/ requestPayResult
```

## 接口说明

虚拟电子多日票支付结果查询。

## 请求参数

参数详情参见规范表 99。

| 字段 | 类型 | 说明 |
|------|------|------|
| phone | string | 手机号 |
| thirdUserId | String | 用户ID |

## 应答参数

参数详情参见规范表 100。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
