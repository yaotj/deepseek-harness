# if8a_43– 查询月度账单

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/ queryTravelBillStatistics
```

## 接口说明

查询用户月度统计数据。

## 请求参数

参数详情参见规范表 93。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |

## 应答参数

参数详情参见规范表 94。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUid | string | 用户id |
| start | String | 开始时间 yyyyMMddHHmmss 非必填 |
| end | String | 结束时间 yyyyMMddHHmmss 非必填 |
| channel | String | 支付方式 |
