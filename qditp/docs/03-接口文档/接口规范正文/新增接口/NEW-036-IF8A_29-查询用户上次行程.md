# if8a_29 – 查询用户上次行程

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/queryUserItinerary
```

## 接口说明

查询用户最近一次行程信息。

## 请求参数

参数详情参见规范表 75。

| 字段 | 类型 | 说明 |
|------|------|------|
| orderNo | string | 订单号 |
| orderTicketNum | string | 订单数量 |
| actualTakeTicketNum | string | 实际出票数量 |
| takeTickeDate | string | 出票时间 |
| takeTiketFaultReason | string | 出票故障原因 |
| refundAmount | String | 退款金额 |

## 应答参数

参数详情参见规范表 76。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
