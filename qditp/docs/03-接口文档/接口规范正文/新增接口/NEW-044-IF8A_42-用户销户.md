# if8a_42– 用户销户

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/ requestTransStatistics
```

## 接口说明

用户请求销户，清除、转移相关数据。

## 请求参数

参数详情参见规范表 91。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |

## 应答参数

参数详情参见规范表 92。

| 字段 | 类型 | 说明 |
|------|------|------|
| orderNo | string | 协议编码 |
