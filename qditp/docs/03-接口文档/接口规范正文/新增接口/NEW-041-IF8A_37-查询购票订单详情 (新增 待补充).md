# if8a_37 – 查询购票订单详情 (新增 待补充)

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project] /app/requestPayOrderDetail
```

## 接口说明

使用地铁APP扫一扫功能，扫描TVM购票机的二维码，通过手机进行支付。

## 请求参数

参数详情参见规范表 85。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | String | 用户id |
| orderNo | String | 单号 |

## 应答参数

参数详情参见规范表 86。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
| ticketTransRecord | String | 订单详情数据 |
