# IF8B-05 支付结果通知

## 接口地址

```
http//:[ip]:[port]/[project]/app/receivePaymentResult
```

## 接口说明

支付结果回调

## 请求参数

参数详情参见规范表 63。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |

## 应答参数

参数详情参见规范表 64。

| 字段 | 类型 | 说明 |
|------|------|------|
| blackList | Json数组 | 黑名单列表, 最多25笔 |
