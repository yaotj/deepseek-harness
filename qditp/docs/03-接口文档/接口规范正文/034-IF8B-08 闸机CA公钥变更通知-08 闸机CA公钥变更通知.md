# IF8B-08 闸机CA公钥变更通知

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/app/receiveChangeAgmCaKey
```

## 接口说明

闸机更换CA公钥后通知APP_SERVER,APP_SERVER收到CA公钥变更通知后通知客户端更换用户密钥。

## 请求参数

参数详情参见规范表 71。

| 字段 | 类型 | 说明 |
|------|------|------|
| orderNo | string | 订单号 |
| orderTicketNum | string | 订单数量 |
| actualTakeTicketNum | string | 实际出票数量 |
| takeTickeDate | string | 出票时间 |

## 应答参数

参数详情参见规范表 72。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |
