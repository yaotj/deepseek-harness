# IF8B-01 行业数据推送

> 来源：`10-业务规范与标准/原始归档/青岛地铁-ITP与APP接口规范R6.docx`

## 接口地址

```
http//:[ip]:[port]/[project]/ticket/receiveCardDataFromItp
```

## 接口说明

推送行业数据

## 请求参数

参数详情参见规范表 55。

| 字段 | 类型 | 说明 |
|------|------|------|
| retCode | string | 返回码 |
| retMsg | string | 返回消息 |

## 应答参数

参数详情参见规范表 56。

| 字段 | 类型 | 说明 |
|------|------|------|
| thirdUserId | String | 第三方用户id |
| cardId | String | 地铁会员卡号 |
| cardType | String | 2.8	卡类型编码 |
| channel | String | 2.7	支付通道编码 |
