本目录将 R6 接口规范文档按接口拆分为独立文件，文件名采用 **方案 C** 命名：

```
<序号>-<IF8X-XX>-<接口名称>[-<子类型>].md
```

- **序号**：接口在规范中的顺序编号（001-033）
- **IF8X-XX**：规范中的接口编号（IF8A-01 ~ IF8B-08）
- **子类型**：`流程` / `请求参数` / `应答参数` / `通知`（可选）
