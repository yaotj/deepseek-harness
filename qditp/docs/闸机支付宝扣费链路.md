# 闸机支付宝扣费链路

> 记录日期：2026-07-03  
> 涉及模块：fep-dev-server、ticket-server、alipay-pay-sign-server、rpc、model

---

## 一、链路概述

当闸机（AGM）读取支付宝二维码并完成刷卡后，系统通过以下链路完成**免密扣费**：

```
闸机 → fep-dev-server → ticket-server（状态更新+推送）
                    ↓
               支付宝扣费链路
                    ↓
            fep-dev-server → alipay-pay-sign-server → 支付中心 → 支付宝
                    ↓
            返回结果 → 闸机
```

**关键特征**：
- `issueChannelCode=07` 标识支付宝出行渠道
- 免密扣费依赖用户签约状态（`requestSignSeq`）
- 扣费请求由 `fep-dev-server` 在 ticket-server 处理完成后异步触发

## 二、完整时序图

```
闸机（AGM）
    │
    │ ① IF1A-01 检票通知
    │ POST /ci/agm/notiVerifyResult
    │ {cardId, trxType=02/03, issueChannelCode=07, deviceId, handleDateTime, ...}
    │
    ▼
fep-dev-server (DevServiceImpl)
    │
    │ ② 转发闸机通知
    │ ticketClient.notifyVerifyResult(request)
    │
    ▼
ticket-server (TicketRideStatusServiceImpl)
    │
    │ ③ 查询当前 QRCodeStatus
    │ qrCodeStatusMapper.selectByCardId(cardId)
    │
    │ ④ 填充上次交易字段
    │ fillLastTicketFields(request, currentStatus)
    │ - lastTicketStatus = currentStatus.codeStatus
    │ - lastHandleStationCode = currentStatus.lastTxnStation
    │ - lastHandleDateTime = currentStatus.lastTxnTime
    │
    │ ⑤ 写入交易明细
    │ qrCodeTxnDetailMapper.insert(detail)
    │
    │ ⑥ 更新二维码状态
    │ qrCodeStatusMapper.upsert(nextStatus)
    │ - 进站(01) → 04
    │ - 出站(02) → 05
    │ - 超时出站(03) → 06
    │
    │ ⑦ 异步推送行业数据（支付宝渠道）
    │ appNotifyService.notifyVerifyResult(request, nextStatus)
    │ - issueChannelCode=07 推送到 alipayIndustryDataNotifyUrl
    │
    │ ⑧ 异步推进行程数据
    │ appNotifyService.pushAlipayTripData(request, nextStatus, detail)
    │ - POST https://dtcustomer.bestonepay.com/ngopenplatform/notify/pushTransData
    │ - bizData: {logicCard, transType, transTime, transSeq, transStation, ...}
    │
    ▼ 返回 retCode=0000
fep-dev-server (DevServiceImpl)
    │
    │ ⑨ 判断是否需要扣费
    │ shouldPay(request) && ticketResponse.retCode == "0000"
    │
    │ ⑩ 渠道分流
    │ issueChannelCode == "07"
    │     → requestAlipayTripPay(request)
    │ issueChannelCode != "07"
    │     → requestGateTxnPay(request)  [地铁APP免密扣费]
    │
    ▼
requestAlipayTripPay(request)
    │
    │ ⑪ 查询用户签约信息
    │ alipayPaySignClient.selectSignInfo(thirdUserId)
    │ → channelAgreementCode, reqContractNo, cardId, cardType
    │
    │ ⑫ 查询用户手机号
    │ alipayAccountClient.selectByThirdUserId(thirdUserId)
    │ → phone (MSISDN)
    │
    │ ⑬ 查询进站设备
    │ ticketClient.queryEntryDevice(cardId)
    │ → QRCodeTxnDetail SELECT ... WHERE trxType='01' ORDER BY handleDateTime DESC
    │ → entryDeviceCode
    │
    │ ⑭ 构建支付请求
    │ AlipayTripRequestPayReqDTO:
    │ - orderNo = GT + yyyyMMddHHmmssSSS + 卡号后6位
    │ - scene = TRIP
    │ - paymentVendor = ALIPAY
    │ - amount = trxAmount + overtimeAmount（单位：分）
    │ - industryType = 1（地铁）
    │ - subject = "地铁乘车扣费"
    │ - body = "地铁乘车费用"
    │ - requestSignSeq = signInfo.reqContractNo
    │ - thirdUserId = 16进制转10进制
    │ - orderTimeOut = 60
    │ - industryDetail = JSON {
    │     orderDate: "yyyy-MM-dd",
    │     cardIssueCode: "0007",
    │     cardNum: cardId,
    │     channelAgreementNo: channelAgreementCode,
    │     tikcetTransSeq: ticketTransSeq,
    │     entryLineCode: lastHandleStationCode,
    │     entryId: lastTicketStatus,
    │     entryLineName: lastHandleStationCode,
    │     entryStationCode: lastHandleStationCode,
    │     entryStationName: lastHandleStationCode,
    │     entryDeviceCode: entryDeviceCode,
    │     entryDate: lastHandleDateTime,
    │     exitId: ticketTransSeq,
    │     exitLineCode: handleStationCode,
    │     exitLineName: handleStationCode,
    │     exitStationCode: handleStationCode,
    │     exitStationName: handleStationCode,
    │     exitDeviceCode: deviceId,
    │     exitDate: handleDateTime,
    │     orderExpType: trxType,
    │     fineAmount: overtimeAmount,
    │     phone: phone,
    │     cardType: cardType,
    │     ticketFlag: "3"
    │   }
    │
    ▼
    │ ⑮ RPC 调用
    │ POST /api/payment/requestPay
    │ (AlipayTripRequestPayReqDTO)
    │
    ▼
alipay-pay-sign-server (AlipayPaySignServiceImpl)
    │
    │ ⑯ 参数校验
    │ - orderNo/amount/industryType/subject/body/industryDetail 非空
    │ - requestSignSeq 免密场景必填
    │
    │ ⑰ 查询签约信息
    │ alipaySignInfoMapper.selectByThirdUserIdAndChannel(thirdUserId, ALIPAY)
    │
    │ ⑱ 幂等性检查
    │ alipayPayLogMapper.selectByOrderNo(orderNo)
    │ - 已存在则直接返回历史结果
    │
    │ ⑲ 生成商户订单号
    │ merchantOrderNo = payCenterClient.generateMerchantOrderNo()
    │
    │ ⑳ 写入支付流水
    │ alipayPayLogMapper.insert(payLog)
    │ - payStatus = FAIL（初始状态）
    │
    │ ㉑ 调用支付中心
    │ payCenterClient.requestPay(bizDataMap)
    │
    ▼
支付中心 (PayCenterClient)
    │
    │ ㉒ RSA 签名 + HTTP 调用
    │ POST https://dtcustomer.bestonepay.com/ngopenplatform/api/payment/requestPay
    │ bizData: {orderNo, merchantOrderNo, scene, paymentVendor, amount,
    │           industryType, subject, body, requestSignSeq, thirdUserId,
    │           orderTimeOut, industryDetail, ...}
    │
    ▼
支付宝（3.77 接口）
    │
    │ ㉓ 免密扣款 / 主动支付
    │ 返回 {retCode, retMsg, orderNo}
    │
    ▼
alipay-pay-sign-server
    │
    │ ㉔ 更新本地支付流水
    │ - payStatus = SUCCESS / FAIL
    │ - responseBody / resultCode / resultMsg
    │
    │ ㉕ 返回响应
    │ AlipayTripRequestPayRespDTO {retCode, retMsg, orderNo}
    │
    ▼
fep-dev-server
    │
    │ ㉖ 记录扣费结果日志
    │ log.info("支付宝交通乘车码扣费响应, 返回={}", payResponse)
    │
    │ ㉗ 返回 ticketResponse 给闸机
    │
    ▼
闸机（AGM）
    │
    │ ㉘ 放行 / 提示
    │
```

## 三、核心接口清单

### 3.1 闸机检票通知

| 项目 | 内容 |
|------|------|
| 接口名称 | IF1A-01 闸机检票通知 |
| 请求路径 | `POST /ci/agm/notiVerifyResult` |
| 调用方 | 闸机（AGM） |
| 接收方 | fep-dev-server |
| 关键字段 | `cardId`、`trxType`（01进站/02出站/03超时出站）、`issueChannelCode`（07支付宝）、`deviceId`、`handleDateTime`、`ticketTransSeq` |

### 3.2 支付宝出行支付

| 项目 | 内容 |
|------|------|
| 接口名称 | 1.1 支付宝出行-支付(新增) |
| 请求路径 | `POST /api/payment/requestPay` |
| 调用方 | fep-dev-server（通过 RPC） |
| 接收方 | alipay-pay-sign-server |
| 支付平台 | `https://dtcustomer.bestonepay.com/ngopenplatform/api/payment/requestPay` |
| 关键字段 | `orderNo`、`scene=TRIP`、`paymentVendor=ALIPAY`、`amount`、`industryDetail` |

### 3.3 行程数据推送

| 项目 | 内容 |
|------|------|
| 接口名称 | 3.74 支付宝出行-行程数据推送 |
| 请求路径 | `POST /notify/pushTransData` |
| 调用方 | ticket-server（异步） |
| 接收方 | 支付宝 |
| 推送地址 | `https://dtcustomer.bestonepay.com/ngopenplatform/notify/pushTransData` |

### 3.4 行业数据推送

| 项目 | 内容 |
|------|------|
| 接口名称 | IF8B-01 行业数据推送 |
| 请求路径 | `POST /notify/receiveCardDataFromItp` |
| 调用方 | ticket-server（异步） |
| 接收方 | 支付宝 |
| 推送地址 | `https://dtcustomer.bestonepay.com/ngopenplatform/notify/receiveCardDataFromItp` |

## 四、数据存储

### 4.1 ticket-server 数据表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `QRCODE_STATUS` | 二维码乘车状态 | `cardId`、`codeStatus`（04进站/05出站/06超时）、`lastTxnTime`、`lastTxnStation`、`txnSeq` |
| `QRCODE_TXN_DETAIL` | 闸机交易明细 | `cardId`、`trxType`、`deviceId`、`handleDateTime`、`handleStationCode`、`trxAmount`、`overtimeAmount`、`ticketTransSeq` |

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `ALIPAY_PAY_LOG` | 支付宝支付流水 | `paySeq`、`orderNo`、`tradeNo`、`payAmount`、`payStatus`、`scene`、`industryDetail`、`createTime` |
| `ALIPAY_SIGN_INFO` | 用户签约信息 | `thirdUserId`、`cardId`、`agreementCode`（requestSignSeq）、`channelAgreementCode` |

### 4.3 alipay-account-server 数据表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `ALIPAY_USER_INFO` | 支付宝用户信息 | `thirdUserId`、`cardId`、`msisdn`（phone） |

## 七、已知问题与后续优化

### 7.1 已知问题

| 问题 | 影响 | 解决方案 |
|------|------|---------|
| `entryId` 使用 `lastTicketStatus`（状态码）而非真实交易ID | 行业详情中进站交易ID不准确 | 需扩展闸机接口或从历史记录查询真实 entryId |
| `entryLineCode`/`entryLineName` 用站点编码兜底 | 线路信息不准确 | 后续通过 `StationInfoMapper` 查询真实线路代码 |
| `channelAgreementNo` 之前为空 | 已修复，现从 `AlipaySignInfo.channelAgreementCode` 获取 | - |
| `phone` 之前为空 | 已修复，现从 `AlipayUserInfo.msisdn` 获取 | - |
