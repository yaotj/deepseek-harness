    文档内容概览

    • WebFlux 版：Spring Cloud Gateway 基于 Spring WebFlux（响应式）的核心实现，包含路由、断言、过滤器工厂、全局过滤器、TLS、安全、配置、Actuator、故障排查、开发者指南、AOT/原生镜像支持、全部配置属性。
    • Web MVC 版：Spring Cloud Gateway Server Web MVC（基于 Servlet 的网关实现），包含 Java Routes API、请求断言、处理器过滤器函数等。
    • Proxy Exchange：基于 Spring Web MVC 或 WebFlux 的代理交换网关。
    • 附录：Common application properties（常用配置属性全表）。
