# 工作汇报归档

本目录统一存放项目的工作汇报类文档：**日报、周报、月报**等。

## 命名规范

| 类型 | 文件名格式 | 示例 |
|---|---|---|
| 日报 | `YYYY-MM-DD-工作日报.md` | `2026-10-26-工作日报.md` |
| 周报 | `YYYY-Www-工作周报.md` | `2026-W44-工作周报.md` |
| 月报 | `YYYY-MM-工作月报.md` | `2026-10-工作月报.md` |

## 日报标准结构（四段式）

1. **一、今日完成工作** —— 说结果、说人话，避免技术黑话（端口号/kubectl/命令细节移出正文）。
2. **二、明日 / 后续计划**
3. **三、问题与风险** —— 按高/中/低分级。
4. **四、需协调 / 支持事项**

> 技术实现细节、命令、配置契约等请勿写进日报正文；如需沉淀，记入 `docs/tracking/`（IT 问题档）或对应架构文档。
