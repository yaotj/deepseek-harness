## 一、今日完成工作

**1. 红岛生产环境服务内部地址打通（内网化）**
把红岛生产环境里各业务系统之间的互相调用、以及网关到后端的访问，全部改为"集群内部地址"，不再依赖对外公开的端口。好处：更安全，且外部端口变动不会影响内部调用。
- 已完成 20 个业务系统的内网地址配置、网关路由调整；
- 完成 92 处服务间调用地址切换，全部验证通过。

**2. 统一接入集中日志系统（VL 日志）**
给红岛生产环境 22 个 Java 业务系统全部接入了集中日志平台（VictoriaLogs），排查问题时可直接在日志平台查看各系统运行日志。

**3. 服务互调地址修正（问题编号 IT-016）**
修正了红岛环境里 14 个系统共 78 处"服务互相调用地址"的错误（原本指向测试环境），已全部改为红岛生产环境正确地址，并登记为已解决。

**4. 统一 JVM 运行参数（问题编号 IT-020）**
把红岛 21 个 Java 服务的运行内存参数统一调大（堆内存由 500M 提升到 5900M），并固化到平台配置，避免服务重启后被重置。各服务已验证生效。

**5. 应用日志落盘到共享存储（NFS/PVC 试点）**
在红岛生产环境申请了一个 400G 的共享文件存储盘，并选取一个服务（trans-query-server）试点把运行日志写入该盘，验证可行，为后续各系统日志统一集中存储打基础。

**6. 协助排查数据库连不上问题（问题编号 IT-021）**
红岛生产环境多个系统在启动时连接数据库报"连接被重置"。经独立探测确认：网络是通的，问题出在数据库认证/连接阶段。初步怀疑是数据库连接数被打满（今日多次重启叠加导致连接数暴涨）。已给出排查方向，待 DBA 进一步定位。
